# Project status and engineering notes

This document records the boundary between what this repository is intended to demonstrate, what has been verified in the repository, and what still needs evidence. It is deliberately more specific than a feature list.

## Current stage

**Research prototype**

## Why this exists

I built this to make the first pass of county-level industry desk research reproducible: collect public material, preserve evidence links, and turn the material into a reviewable Markdown draft.

## Scope and known limitations

The generated report is a research draft, not a factual finding or policy recommendation. Search coverage varies by county and provider; LLM synthesis can omit context or make unsupported inferences. Mock mode verifies control flow only and must not be read as evidence.

## Next evidence to collect

Add one reviewed, source-checked report per mode and document the correction process when a generated claim is rejected.

## Maintenance rule

Future changes should describe one concrete behavior, include the smallest relevant verification step, and update this document whenever the project boundary changes.
