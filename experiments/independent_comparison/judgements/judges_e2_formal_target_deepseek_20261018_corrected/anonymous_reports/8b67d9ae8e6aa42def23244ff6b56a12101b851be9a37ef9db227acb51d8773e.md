# 长汀县 生态治理、工业发展与文旅融合产业研究报告

> 生成日期: 2026-10-18 14:40 UT[GROUP]  
> 报告版本: 0.1.0

## 执行摘要

长汀县产业格局呈"服务业主导、工业换挡、生态转化起步"特征，生态治理与文旅融合处于成长期，工业处于转型期，三链中观数据系统性缺失是当前最大制约。

**关键发现**

- **产业规模与地位**：2024年GDP达357.8亿元、增长4.9%，第三产业以180.5亿元、7.1%增速贡献过半经济总量，是县域经济第一支柱；工业增加值133.5亿元、仅增3.0%，为三次产业中最慢部门。

- **最突出优势**：生态治理的制度化先发优势已经确立——2025年入选全国首批一体化推进水土保持工程建设县，为"水保+产业"融合转化提供了国家级平台背书；同时第三产业增速领跑，显示生态文旅带动的服务消费具备现实拉力。

- **最关键瓶颈**：三条产业链的中观环节数据系统性缺失——工业无规上企业数与行业产值，文旅无游客人次与收入，林下经济无面积与产值拆分，生态治理尚无独立经济核算口径，导致无法支撑精准的阶段判断与政策设计。

- **最紧迫行动**：优先补齐统计口径短板，推动林下经济、生态文旅产值从第一、第三产业中单列核算，同步建立文旅专项指标与工业行业结构台账，为后续政策资源配置提供可验证的数据基础。

**决策建议**

- **以统计口径建设为先手**：将生态治理衍生经济（林下经济、生态文旅）纳入县级统计单列科目，明确核算边界与责任部门，解决"有实践、无数据"的决策盲区。

- **工业走"存量提质"而非"增量扩张"**：在增速换挡期，优先摸清规上企业与行业结构底数，聚焦现有存量企业的技改升级与链条延伸，避免在结构不清的情况下盲目铺新摊子。

- **文旅以生态治理成果为核心卖点做深融合**：依托全国首批一体化水保工程建设县品牌，将水土保持治理成果转化为可体验、可消费的文旅产品，但须先建立游客人次与收入监测体系，以数据验证投入产出后再扩大规模。

## 一、产业现状分析

# 长汀县生态治理、工业发展与文旅融合产业现状分析

> 数据基准日：2026-10-18；经济数据为2024年度快报口径（材料[1]），使用时需保留时间点与修订说明。


## 1. 产业概况

### 1.1 产业规模与经济地位

2024年长汀县实现地区生产总值357.8亿元，同比增长4.9%。三次产业结构为：第一产业43.9亿元（占12.3%，增长2.5%）、第二产业133.5亿元（占37.3%，增长3.0%）、第三产业180.5亿元（占50.5%，增长7.1%）（材料[1]）。

从研究方向看：

- **生态治理相关产业**（林下经济、水土保持衍生生态农业等）：具体产值数据缺失。材料[2]仅定性表述"做强林下经济、做优生态文旅、做精产业融合"，未给出细分产值。可确认的是，第一产业增加值43.9亿元中包含林下经济贡献，但拆分比例数据缺失。
- **工业**：第二产业增加值133.5亿元，占GDP 37.3%，增速3.0%，低于GDP整体增速（4.9%）和第三产业增速（7.1%），是三次产业中增长最慢的部门（材料[1]）。
- **文旅融合**：归入第三产业，第三产业增加值180.5亿元、增长7.1%，为三次产业中增速最快者，占GDP过半（50.5%）（材料[1]）。但文旅在其中的具体贡献额数据缺失。

**结论**：第三产业（含文旅）是长汀经济的第一大部门和增长主引擎；工业占比次之但增速偏弱；生态治理尚缺乏独立的经济核算口径，其价值主要通过第一产业（林下经济）和生态文旅间接体现。

### 1.2 发展历程（关键节点）

- **水土保持起步**：长汀是我国南方红壤区水土流失治理的典型区域，历史上以"火焰山"治理闻名（此为公开常识背景，材料[1][2]未展开具体年份，细节数据缺失）。
- **2025年**：入选全国首批一体化推进水土保持工程建设县（材料[2]，福建省人民政府门户网站，2025-05-11），标志生态治理从单一水保工程向"水保+产业"一体化转型。
- **2024年**：GDP达357.8亿元，第三产业占比过半，生态文旅与林下经济被列为生态价值转化路径（材料[1][2]）。


## 2. 产业链结构

### 2.1 生态治理—林下经济链

- **上游**：种源、苗木、水保工程装备——数据缺失。
- **中游**：林下种植/养殖（林下经济）——材料[2]确认其为生态价值转化抓手，但品种结构、产量数据缺失。
- **下游**：生态农产品销售、生态文旅应用——数据缺失。
- **长汀位置**：强项在水土流失治理工程能力与生态本底修复（全国首批一体化水保工程建设县，材料[2]）；弱项在林下经济的产品加工深度与品牌化，缺乏可验证的产值数据支撑。

### 2.2 工业链

- 材料[1][2]均未提供工业细分行业、规上企业数量、主要产品等结构信息，**产业链上中下游具体构成数据缺失**。
- 可判断的仅是全量特征：第二产业增加值133.5亿元、增速3.0%，占GDP 37.3%（材料[1]），增长动能弱于第三产业。

### 2.3 文旅融合链

- **上游**：生态资源（水土保持治理成果）、文化资源——资源本底明确，开发主体数据缺失。
- **中游**：景区/文旅项目运营——数据缺失。
- **下游**：游客消费、生态文旅产品销售——数据缺失。
- **长汀位置**：材料[2]将"生态文旅"列为生态价值转化三大路径之一，第三产业增速7.1%为三次产业最高（材料[1]），显示文旅带动的服务消费是相对强项；但文旅总收入、游客人次等核心指标在两份材料中均未披露。

**产业链总体判断**：现有材料仅支持"总量+增速"层面的结构判断，三條产业链的中观环节（企业、产品、产量）数据系统性缺失，需补充统计公报全文或行业专项数据后方可细化。


## 3. 市场主体

- **龙头企业**：材料[1][2]均未点名任何企业，**龙头企业名称、规模、特色数据缺失**。
- **中小企业与合作社数量**：数据缺失。

## 4. 发展阶段判断

综合判断：**生态治理处于成长期（政策驱动型），工业处于转型期（增速换挡），文旅融合处于成长期**。

判断依据：

1. **生态治理—成长期**：2025年入选全国首批一体化推进水保工程建设县（材料[2]），说明其从"治理达标"迈向"治理+产业一体化"的制度化阶段，但林下经济、生态文旅的产值拆分尚未进入统计公报口径（材料[1]未单列），产业化核算体系不成熟，符合成长期特征。
2. **工业—转型期**：第二产业增速3.0%，低于GDP增速4.9%和第三产业增速7.1%（材料[1]），占比37.3%但动能减弱，呈典型"存量支撑、增量乏力"的转型期特征；因缺乏行业结构数据，无法进一步判断是结构性升级还是收缩。
3. **文旅融合—成长期**：第三产业增速7.1%领跑三次产业、占比达50.5%（材料[1]），生态文旅被明确列为生态价值转化路径（材料[2]），但文旅专项指标（收入、人次、项目数）均缺失，尚无法确认是否进入成熟期。

**数据缺口提示**：若要支撑更精确的阶段判断与可落地建议，需补充：①统计公报全文中工业规上企业数与行业产值；②文旅游客人次与收入；③林下经济面积与产值；④水保工程投资额与生态产品交易数据。现有两份材料仅能支撑总量与增速层面的结论。
