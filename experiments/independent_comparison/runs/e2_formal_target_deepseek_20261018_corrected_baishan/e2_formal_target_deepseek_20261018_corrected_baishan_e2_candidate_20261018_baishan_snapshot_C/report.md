# 白山市 产业结构与资源型经济产业研究报告

> 生成日期: 2026-10-18 14:38 UTC  
> 报告版本: 0.1.0

## 执行摘要

白山市资源型经济已过成熟期峰值，正处于工业收缩、服务业被动抬升的转型期，核心问题是“上游强、中游弱”的产业链格局尚未扭转。

- **产业规模与地位**：2024年全市GDP 567.85亿元、增长3.4%，三次产业结构为12.8:24.9:62.3，三产占比虽高但主要源于工业收缩后的被动抬升，而非服务业充分发育。
- **最突出的优势**：资源禀赋与上游供给端仍是基本盘，第一产业增加值增长4.7%、一产投资增长37.9%，特色农林资源端的投入正在加大。
- **最关键的瓶颈**：中游精深加工严重薄弱，规上工业增加值下降5.3%、二产投资下降27.2%，资源就地转化增值能力不足，产业链整体处于“上游资源输出、中游加工薄弱、下游关联不足”的位置。
- **最紧迫的行动**：扭转二产投资持续下滑趋势，推动资本从传统资源加工向中游精深加工和特色农林资源转化领域集中，避免服务业高占比掩盖产业空心化风险。
- **转型信号已现但新动能未成**：基础设施投资增长64.7%、民间投资增长55.2%，资本正从传统产业退出转向基建与农业资源端，但GDP增速仅3.4%、二产增速仅0.2%，尚无新的主导产业形成支撑。

**决策建议**

1. **聚焦中游突破**：围绕特色农林资源（人参、林下经济等）和矿产资源的精深加工环节定向招商与扶持，把上游资源优势转化为加工增值优势，扭转“上游强、中游弱”格局。
2. **稳住工业基本盘**：遏制二产投资持续下滑，对现有149户规上工业企业分类施策，区分退出类与可转型类，避免工业动能断崖式收缩。
3. **补齐数据短板**：资源型产业专项产值、主要矿产品产量、园区与企业名录等关键数据在公开材料中缺失，建议优先建立资源型经济专项统计监测，为精细化决策提供依据。

## 一、产业现状分析

# 白山市产业结构与资源型经济现状分析

> 说明：白山市为吉林省地级市，本文按“县域产业分析”框架对其市域产业结构与资源型经济特征进行剖析。数据采集日期2026-10-18，主要依据2024年统计公报（材料[1][2]）。部分细分数据（如资源型产业单独产值、从业人数、企业名录）在公开材料中缺失，已明确标注。


## 1. 产业概况

### 1.1 产业规模

2024年白山市实现地区生产总值**567.85亿元**，比上年增长3.4%（材料[1][2]）。三次产业增加值分别为：

| 产业 | 增加值（亿元） | 增速 |
|------|--------------|------|
| 第一产业 | 72.80 | +4.7% |
| 第二产业 | 141.38 | +0.2% |
| 第三产业 | 353.67 | +4.3% |

规模以上工业：全市149户规上工业企业增加值**同比下降5.3%**（材料[1]），是三次产业中唯一负增长板块，显示工业尤其是传统资源型工业承压明显。

> 资源型经济专项产值、主要矿产品产量、工业从业人数：**数据缺失**（公开材料未列示）。

### 1.2 在经济中的地位

- 三次产业结构为 **12.8 : 24.9 : 62.3**（材料[1]），呈现典型的“三产主导、二产偏弱”格局。
- 第二产业占比仅24.9%，且增速近乎停滞（+0.2%），说明以资源型工业为核心的第二产业对经济增长的拉动作用显著弱化。
- 第三产业占比高达62.3%、增速4.3%，已成为增长主引擎，但其高占比在一定程度上是工业收缩后的“被动抬升”，而非服务业充分发育的结果。

### 1.3 发展历程（关键节点）

公开材料未提供历史序列数据，**具体关键节点数据缺失**。从现有结构特征可作阶段性判断：白山作为传统资源型城市（林业、矿产、能源），经历了资源开发支撑期→资源约束与工业收缩期→服务业替代与转型探索期的演进路径。2024年二产投资下降27.2%、基础设施投资增长64.7%（材料[1]），反映当前正处于投资结构从产业扩张转向基础设施补短板的转型阶段。


## 2. 产业链结构

资源型经济产业链在公开材料中缺乏分环节明细，以下结合结构数据作框架性判断，具体环节数据缺失处已标注。

### 2.1 上游（原材料/种源/装备）

- 白山资源型产业上游以林木、矿产、能源等自然资源开采与初加工为主。**具体矿种、储量、开采量数据缺失**。
- 第一产业投资增长37.9%（材料[1]），显示农林资源端投入加大，可能与特色农林产品（人参、林下经济等）种源与基地建设相关，但**细分品类数据缺失**。

### 2.2 中游（生产/加工）

- 规上工业增加值下降5.3%（材料[1]），中游加工环节整体收缩，是产业链最薄弱、承压最重的环节。
- 第二产业投资下降27.2%（材料[1]），意味着中游产能扩张停滞甚至退出，加工深度不足、附加值偏低的问题突出。

### 2.3 下游（销售/出口/应用）

- 下游应用与销售数据**缺失**（无出口额、主要产品销量数据）。
- 第三产业增长4.3%、占比62.3%，下游服务与流通环节相对活跃，但缺乏与本地资源加工品的强关联证据。

### 2.4 本县在产业链中的位置

**强项**：资源禀赋与上游原材料供给（第一产业投资+37.9%、一产增加值+4.7%）。
**弱项**：中游精深加工（规上工业-5.3%、二产投资-27.2%），产业链整体处于“上游资源输出、中游加工薄弱、下游关联不足”的位置，资源就地转化增值能力偏弱。


## 3. 市场主体

- **龙头企业**：公开材料未列示具体企业名称、规模与特色，**数据缺失**。
- **中小企业与合作社数量**：**数据缺失**。仅知规上工业企业149户（材料[1]），可作为工业市场主体规模的间接参照。
- **产业集群/园区**：**具体园区名称与产值数据缺失**。从投资结构看，基础设施投资增长64.7%、民间投资增长55.2%（材料[1]），反映园区载体与民间资本活跃度提升，但缺乏园区层面的量化佐证。


## 4. 发展阶段判断

**判断：处于“成熟后期—转型期”**，依据如下：

1. **资源型工业收缩**：规上工业增加值-5.3%、二产投资-27.2%（材料[1]），传统资源加工动能衰退，符合资源型经济成熟后期特征。
2. **结构被动服务化**：三产占比62.3%但二产近乎零增长，服务业高占比更多源于工业收缩而非产业升级，是转型期的典型信号。
3. **投资结构转向**：基础设施投资+64.7%、民间投资+55.2%、一产投资+37.9%，而二产投资大幅下降，表明资本正从传统产业退出、转向基建与农业资源端，处于动能转换的转型探索阶段。
4. **增长动力偏弱**：GDP增速3.4%、二产增速0.2%，整体处于低速调整期，尚未形成新的主导产业支撑。

**结论**：白山资源型经济已过成熟期峰值，正处在依赖资源存量、工业收缩、寻求替代动能的转型期；下一步关键在于推动中游精深加工与特色农林资源转化，扭转“上游强、中游弱”的产业链格局。受公开数据限制，资源型产业专项产值、企业名录、园区数据等需进一步补充采集以支撑精细化决策。
