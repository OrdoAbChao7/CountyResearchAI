# 于都县 产业结构与工业发展产业研究报告

> 生成日期: 2026-10-18 14:37 UTC  
> 报告版本: 0.1.0

## 执行摘要

于都县2024年产业结构呈"三产体量大、二产动力强"格局，工业以9.7%增速成为增长主引擎，规上工业增速达13.8%，整体处于工业化中期加速扩张的成长期。

**关键发现**

- **产业规模与地位**：2024年全县GDP 352.61亿元（增长4.9%），三次产业结构为10.6:32.6:56.8；工业增加值94.79亿元、占GDP 26.9%，规上工业总产值209.08亿元、增长11.7%，工业增速显著高于GDP和三产（3.0%），是拉动增长的核心力量。

- **最突出优势**：增长动能与投资意愿双强——规上工业增速（13.8%）远高于整体工业（9.7%），二产投资增长15.7%、高出总投资约8个百分点，产销率98.1%显示产能释放与市场需求同步、库存压力小，具备加速扩张的典型特征。

- **最关键瓶颈**：结构诊断数据严重缺失——产业链上中下游构成、主导加工行业、龙头企业与园区载体、从业人数、出口结构等关键细分数据均未覆盖，导致无法判定于都在产业链中的实际分工位置与集群能级，目前只能做"总量判断"、难以做"结构诊断"。

- **最紧迫行动**：补采分行业产值、规上企业名录与园区数据、出口交货值三类基础数据，尽快将分析从总量层面下沉到结构与主体层面，为产业定位和集群评估提供依据。

**决策建议**

1. **巩固工业扩张势头**：保持二产投资强度，重点跟踪规上企业产能释放与产销衔接，防止增速回落，稳住增长主引擎。

2. **启动产业结构摸底**：由工信部门牵头，系统梳理主导行业、龙头企业、园区载体与配套能力，明确产业链位置与附加值水平，为精准施策提供底数。

3. **前瞻布局转型准备**：在成长期窗口内同步关注传统产业占比与新兴产业接续情况，避免"增速尚好、结构未优"的风险累积。

## 一、产业现状分析

# 于都县产业结构与工业发展现状分析

> 数据基准：2024年（采集日期2026-10-18）。原始材料仅含统计公报核心指标，部分细分数据缺失，已如实标注。


## 1. 产业概况

### 1.1 产业规模

2024年于都县实现地区生产总值 **352.61亿元**，按可比价同比增长4.9%（材料[1][2]）。三次产业增加值分别为：

| 产业 | 增加值（亿元） | 增速（可比价） | 占GDP比重 |
|------|--------------|--------------|----------|
| 第一产业 | 37.29 | 3.6% | 10.6% |
| 第二产业 | 115.03 | 8.6% | 32.6% |
| 第三产业 | 200.29 | 3.0% | 56.8% |

工业层面，全县实现**工业增加值94.79亿元**，增长9.7%，占GDP比重 **26.9%**；其中规模以上工业增加值增长 **13.8%**，规模以上工业总产值 **209.08亿元**，增长11.7%，工业产销率98.1%（材料[1]）。

> 注：从业人数、主要产品产量等细分数据在原始材料中**数据缺失**，需补充统计年鉴或工信部门数据。

### 1.2 在经济中的地位

- **工业是增长主引擎**：工业增加值增速9.7%、规上工业增速13.8%，均显著高于GDP增速（4.9%）和第三产业增速（3.0%），是拉动全县增长的核心力量。
- **二产占比32.6%**，工业占GDP 26.9%，处于工业化中期的典型区间；三产占比56.8%但增速仅3.0%，呈现"三产体量大、二产动力强"的结构特征。
- **投资结构向二产倾斜**：第二产业投资增长15.7%，高于第三产业投资（9.1%）和总投资（7.7%），表明工业扩张仍在加速（材料[1]）。

### 1.3 发展历程（关键节点）

原始材料未提供历史序列数据，**发展历程的完整梳理数据缺失**。可确认的节点为：根据第五次全国经济普查结果，2023年GDP修订为340.03亿元，2024年以修订后数据为基数核算（材料[2]），说明统计口径已按五经普校准，2024年数据具备可比性基础。


## 2. 产业链结构

> 原始材料仅提供总量与增速指标，**未披露分行业、分环节的产业链明细**。以下基于可得数据做结构性判断，具体环节构成需补充行业普查数据。

### 2.1 上游（原材料/装备）

**数据缺失**。材料未列明规上工业的行业构成，无法判断原材料本地配套率与装备来源。可参考的间接信号：二产投资增长15.7%（材料[1]），说明产能扩张投入较大，但投向的具体环节不明。

### 2.2 中游（生产/加工）

规上工业总产值209.08亿元、产销率98.1%（材料[1]），产销衔接良好，说明中游加工环节产出基本实现当期销售，库存压力小。但**主导加工行业（如纺织服装、电子、食品等）的具体构成数据缺失**，无法判定中游以哪类加工为主。

### 2.3 下游（销售/出口/应用）

**数据缺失**。材料未提供出口交货值、内销/外销结构。产销率98.1%仅反映整体产销平衡，不能区分本地消化与外销比例。

### 2.4 本县在产业链中的位置

基于现有数据可做的判断：
- **强项信号**：规上工业增速（13.8%）远高于整体工业（9.7%），说明规上企业扩张快于小微工业，产业集中度可能在提升；产销率98.1%表明供给与市场需求匹配度较高。
- **弱项/不确定**：产业链上中下游的具体分工位置、本地配套能力、附加值水平均**缺乏数据支撑**，无法判断于都处于"原料输出型""加工制造型"还是"品牌应用型"位置。这是本次分析最大的数据缺口。

## 4. 发展阶段判断

### 结论：处于**成长期**（工业化加速扩张阶段）

### 判断依据

1. **增速结构支持成长期判断**：规上工业增加值增长13.8%、工业增加值增长9.7%，均处两位数或接近两位数区间，显著高于GDP增速，符合成长期"工业快于整体、规上快于平均"的典型特征（材料[1]）。
2. **投资持续加码**：第二产业投资增长15.7%，高于总投资增速7.7%约8个百分点（材料[1]），资本形成仍在扩张，是成长期而非成熟期（成熟期投资通常趋缓）的信号。
3. **产销率高、库存压力小**：98.1%的产销率说明产能释放与市场需求同步，未见成熟期常见的产能过剩迹象（材料[1]）。
4. **工业化水平适中**：工业占GDP 26.9%、二产占32.6%，尚未进入后工业化阶段，但已脱离农业主导，处于工业化中期加速段。

### 尚不能确认的部分

- 是否已进入"转型期"（如从劳动密集型向技术密集型切换），因**缺乏行业结构、研发投入、亩均效益等数据**，无法判断。若后续数据显示传统产业占比高且增速放缓、新兴产业尚未接续，则需上调为"成长期后段/转型前夜"。
- 发展阶段的精确刻度（成长期早/中/晚段）需企业户数、就业结构、人均工业增加值等数据支撑，当前**数据缺失**。


## 小结与数据补强建议

于都县2024年产业结构呈现"三产体量大、二产动力强"的格局，工业以9.7%的增速成为增长主引擎，规上工业13.8%的增速和二产投资15.7%的增速共同指向**成长期加速扩张**的判断。但本次材料仅覆盖总量指标，**产业链环节构成、市场主体名录、园区载体、从业人数、出口结构等关键细分数据均缺失**，导致产业链定位和集群评估无法落地。建议补采：①统计年鉴分行业产值表；②工信局规上企业名录与园区数据；③海关/商务部门出口交货值。补齐后方可完成从"总量判断"到"结构诊断"的升级。
