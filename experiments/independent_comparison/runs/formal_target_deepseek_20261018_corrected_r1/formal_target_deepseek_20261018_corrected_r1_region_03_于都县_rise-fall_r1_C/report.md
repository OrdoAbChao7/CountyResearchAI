# 于都县县域产业兴衰规律研究报告

> 生成日期: 2026-10-18 14:26 UTC
> 报告版本: 0.2.0
> 研究模式: 产业兴衰规律 (rise-fall)

## 执行摘要

于都县产业兴衰的核心判断是：以纺织服装、矿产加工等传统劳动密集型与资源型产业为长期单一支柱，形成路径锁定；2000年代后依托九丰能源、天键股份两家上市企业及工业强县战略初步走向多元支撑，但传统产业占比仍高、附加值偏低，叠加青壮年与高技术人才持续外流，构成“路径锁定+人才流失”的混合型兴衰路径，当前处于转型阵痛期而非衰退期。

**关键发现**

- **起家产业与原始积累路径**：于都县长期以纺织服装、矿产加工等传统劳动密集型与资源型产业为单一支柱，产业结构高度集中，形成典型的路径锁定格局（具体起家产业数据不足，需补充地方志）。
- **壮大期的核心驱动因子**：2000年代后，九丰能源、天键股份相继上市，成为县域产业实力增强与多元支撑格局形成的标志性驱动力量，工业强县战略同步引领产业结构转型。
- **关键拐点**：2025年全县规上工业总产值预计达237亿元、同比增长5.6%，规上营业收入226亿元，营收低于产值，显示附加值偏低的结构性问题仍然突出；2025—2026年启动工业强县及科技创新（含人才引进）领域“十五五”规划编制专题调研，标志政策层面对转型瓶颈的正式回应。
- **衰落/转型的核心机制**：产业结构单一与路径依赖（severity=0.6）叠加人才流失与创新能力不足（severity=0.6），辅以产业转移与成本竞争压力（severity=0.5）、制度与要素配置滞后（severity=0.5），共同构成转型阵痛期的核心约束。
- **人才流失现状**：现有材料仅披露2025年产业规模数据，未提供户籍人口、常住人口、净流出规模及流失人群的年龄、学历、技能结构与主要流向地等信息，人才流失的规模与结构尚无法量化，产业因素对人才流失的影响亦缺乏就业岗位供需匹配数据支撑。
- **兴衰模型归纳**：于都县呈现“路径锁定+人才流失”叠加的混合型兴衰路径——传统产业锁定形成转型惯性，人才外流削弱创新与要素配置能力，二者互馈使县域处于转型阵痛期，而非进入衰退通道。

**历史规律启示**

- **路径锁定的自我强化规律**：以单一劳动密集型或资源型产业起家的县域，即便培育出上市企业并启动工业强县战略，传统产业占比高、附加值偏低（2025年营收226亿元低于产值237亿元）的结构惯性仍会持续压制转型速度，投资者与创业者需以“营收/产值比”等附加值指标而非产值增速判断转型实质进展。
- **人才流失与产业升级的互馈规律**：人才外流与创新能力不足往往互为因果，在缺乏人口流出规模、结构与流向数据的情况下，产业政策对人才流失的干预效果难以评估；决策者应将人才统计指标纳入产业规划基础数据体系，避免以产业规模数据替代要素配置诊断。
- **转型阵痛期的机会窗口规律**：混合型兴衰路径下，县域并非线性衰退，而是处于旧动能锁定与新动能培育并存的阵痛期，上市企业带动与政策规划编制（2025—2026年）构成结构性机会窗口，但其兑现取决于制度与要素配置滞后的破解程度，而非单纯依赖企业数量增长。

## 六、衰落机制

导致该县产业衰落(或面临衰退风险)的核心因子:

### 1. 产业结构单一与路径依赖（严重程度: 60%）

于都县长期依赖传统产业（如纺织服装、矿产加工等劳动密集型与资源型行业），产业结构单一。虽然材料提及“产业结构实现从单一依赖传统产业向多元支撑格局的转变”，但这一转变尚处于初期，传统产业占比仍然较高。当传统产业面临成本上升、需求波动或外部竞争时，县域经济缺乏足够的多元产业缓冲，导致整体增长乏力。规上工业总产值增速仅5.6%，营业收入226亿元低于总产值237亿元，显示产品附加值低、盈利空间受挤压，产业转型阵痛明显。

**证据支撑**:
- 材料[1]：预计2025年全县规上工业总产值237亿元，同比增长仅5.6%，增速偏低
- 材料[1]：规上营业收入226亿元低于总产值237亿元，反映库存积压或价格下行压力
- 材料[1]：明确提及“产业结构实现从单一依赖传统产业向多元支撑格局的转变”，反证此前单一依赖程度高
### 2. 人才流失与创新能力不足（严重程度: 55%）

于都县作为内陆县域，青壮年劳动力与高技术人才持续外流至沿海发达地区，导致本地产业升级缺乏人力资本支撑。材料将“人才引进”与“科技创新”并列为专题调研内容，侧面反映人才短缺已成为制约产业强县建设的瓶颈。人才流失不仅削弱企业技术创新能力，还导致消费市场萎缩、产业空心化风险加剧，使县域在承接产业转移和培育新兴产业时面临“招不来、留不住”的困境。

**证据支撑**:
- 材料[1]：专题调研报告标题明确包含“人才引进”领域，说明人才问题被列为重点议题
- 材料[1]：将“科技创新（含人才引进）”与“工业强县”并列，暗示创新与人才是当前短板
- 材料[1]：新增上市企业仅两家（九丰能源、天键股份），创新型企业数量偏少，反映创新生态薄弱
### 3. 产业转移与成本竞争压力（严重程度: 50%）

于都县传统劳动密集型产业（如纺织服装）面临东南亚及中西部更低成本地区的双重挤压。随着沿海地区产业升级，部分低端环节虽可能转移至于都，但更多是被成本更低的地区截流。本地企业利润空间被压缩，加之县域营商环境、物流配套相对薄弱，导致部分企业外迁或缩减投资，产业集聚效应难以形成，制约了工业强县目标的实现。

**证据支撑**:
- 材料[1]：规上营业收入（226亿元）低于总产值（237亿元），显示产品价格竞争力不足、盈利承压
- 材料[1]：增速仅5.6%，低于全国规上工业平均增速水平，反映外部竞争压力
- 材料[1]：提出“建设工业强县”目标本身即暗示当前工业基础尚不牢固，存在被边缘化风险
### 4. 制度与要素配置滞后（严重程度: 45%）

县域在产权改革、营商环境优化、土地与金融要素配置等方面存在制度性滞后，制约产业转型升级。材料以“十五五”规划编制专题调研形式推进，说明现有政策框架对科技创新和人才引进的支撑不足。上市企业数量少（仅两家）、企业实力“不断增强”但整体规模有限，反映资本市场利用和现代企业制度建设滞后，产业生态尚未形成对新兴产业的有效吸引和培育机制。

**证据支撑**:
- 材料[1]：以“专题调研报告”形式推动规划编制，表明现行制度安排尚不能满足工业强县需求
- 材料[1]：新增上市企业仅九丰能源、天键股份两家，资本市场发育程度低
- 材料[1]：提出“企业实力不断增强”但未给出具体创新指标，暗示制度性支撑体系仍待完善
