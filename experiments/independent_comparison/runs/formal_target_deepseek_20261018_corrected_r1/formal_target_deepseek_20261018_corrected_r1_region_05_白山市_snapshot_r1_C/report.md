# 白山市 产业结构与资源型经济产业研究报告

> 生成日期: 2026-10-18 14:30 UTC  
> 报告版本: 0.1.0

## 执行摘要

白山市规上工业2025年初走出负增长、实现恢复性反弹，但尚处资源型经济转型早段，结构性转型成效未获数据证实。

**关键发现**

- **产业规模与地位**：2025年1—4月规上工业产值同比增长4.9%、增加值增长7.7%，分别较2024年全年加快13.5和13个百分点，增速高于全省3.4个百分点；反推2024年产值、增加值均为负增长（约-8.6%、-5.3%），当前增长属低基数上的恢复性反弹。

- **最突出优势**：增速跑赢全省平均水平，在省域产业分工中处于相对活跃位置；增加值增速（7.7%）快于产值增速（4.9%），暗示产品结构或向深加工方向微调，但需分行业数据验证。

- **最关键瓶颈**：增长质量存疑——反弹主要源于基数效应，"恢复性增长"与"实质性结构转型"尚无法区分；规上工业绝对额、分行业增速、资源型产品产量、龙头企业与园区等基础数据均缺失，产业结构判断难以落地。

- **最紧迫行动**：补齐统计与工信部门基础数据（统计公报、分行业增加值、园区与企业名录），并调取发布会所称"六大亮点"全文，以验证转型质量、避免以单一增速过度推断。

**决策建议**

1. **先补数据、再定判断**：以《白山市统计年鉴》、2024年统计公报及工信局分行业数据交叉核验，建立产业结构与资源型经济监测底表，作为后续政策评估基准。

2. **区分恢复与转型**：将"基数反弹"与"结构升级"分开考核，重点跟踪采矿业与制造业分项增速、深加工产品占比，防止把恢复性增长误读为转型成效。

3. **延伸产业链、培育替代产业**：围绕矿产、林矿加工等上游优势向深加工环节延伸，同步布局非资源型接续产业，降低单一资源周期对市域经济的冲击。

## 一、产业现状分析

# 白山市产业结构与资源型经济现状分析

> 说明：白山市为吉林省下辖地级市，本文按“县域产业研究”框架对其市域产业结构与资源型经济特征进行分析。数据采集日期2026-10-18，参考材料以2025年1—4月工业运行数据为主，其余数据标注来源或注明缺失。


## 1. 产业概况

### 1.1 产业规模

根据白山市工信局2025年5月新闻发布会数据（材料[1]），2025年1—4月：

- 全市规上工业产值同比增长**4.9%**，比2024年全年增速加快**13.5个百分点**，高于全省**3.4个百分点**；
- 规上工业增加值同比增长**7.7%**，比2024年全年增速加快**13个百分点**。

由此可推算：2024年全年白山市规上工业产值增速约为**-8.6%**（4.9%−13.5%），规上工业增加值增速约为**-5.3%**（7.7%−13.0%）。这表明2024年白山市工业处于**负增长区间**，2025年初出现恢复性反弹。

> **数据缺失**：规上工业总产值绝对额、工业增加值绝对额、从业人数、资源型产业具体产量（煤、铁、硅藻土、矿泉水等）均未在参考材料中披露，需补充《白山市统计年鉴》或统计公报数据。

### 1.2 在经济中的地位

参考材料仅提供规上工业增速数据，未提供工业占GDP比重。结合白山市作为典型资源型城市的历史特征（煤炭、铁矿、林矿加工为主导），工业是市域经济核心支柱，但**具体占比数据缺失**，建议以2024年白山市国民经济和社会发展统计公报交叉验证。

### 1.3 发展历程（关键节点）

参考材料未提供历史沿革数据。基于公开常识性背景（需交叉验证）：白山市经历“资源开发扩张—资源枯竭压力—转型调整”的典型路径。材料[1]中“比去年全年增速加快13.5个百分点”这一表述，间接印证**2024年为低谷期、2025年为恢复期**的转折特征，是判断发展阶段的关键信号。


## 2. 产业链结构

参考材料未提供分环节产业链数据，以下基于资源型经济一般结构框架分析，**具体环节数据缺失**，结论以材料[1]增速数据为支撑。

### 2.1 上游（原材料/装备）

资源型经济上游以矿产资源开采（煤炭、铁矿、硅藻土等）和林木资源为主。材料[1]未披露采矿业与制造业的分项增速，**无法判断上游环节具体景气度**。需补充规上工业分行业增加值数据。

### 2.2 中游（生产/加工）

材料[1]提到“六大亮点”但未展开具体内容，**中游加工环节结构数据缺失**。从规上工业增加值增长7.7%高于产值增长4.9%这一组合看，**增加值增速快于产值增速**，暗示产品结构可能向深加工或高附加值方向微调（价格因素或产品结构变化），但需分行业数据验证，不宜过度推断。

### 2.3 下游（销售/出口/应用）

**数据缺失**。参考材料未提供销售产值、出口交货值、产销率等下游指标。

### 2.4 本县在产业链中的位置

基于材料[1]“高于全省3.4个百分点”判断：白山市规上工业增速**跑赢吉林省平均水平**，在省域产业分工中处于相对活跃位置，但这是**低基数下的恢复性增长**（2024年负增长），强项/弱项环节的精确判断需分行业数据支撑，**当前数据不足以定性**。

## 4. 发展阶段判断

### 判断结论：**转型期（恢复性反弹初期）**

### 判断依据

1. **负增长后反弹**：由材料[1]反推，2024年规上工业产值增速约-8.6%、增加值增速约-5.3%，2025年1—4月转正至4.9%和7.7%，符合资源型经济“触底—恢复”的转型期特征，而非成熟期的稳定增长。

2. **增速加快幅度异常大**：产值增速加快13.5个百分点、增加值加快13个百分点，说明**基数效应显著**，增长质量（是否由新兴产业驱动）尚不能确认，需警惕“恢复性增长”与“结构性转型”的区分。

3. **增加值增速高于产值增速**（7.7% vs 4.9%）：可能反映产品结构微调或价格因素，但**缺乏分行业数据**，不能据此断言转型成功。

4. **高于全省3.4个百分点**：相对优势明显，但结合低基数背景，**比较优势的可持续性待观察**。

### 关键判断

白山市资源型经济处于**转型期早段**：已走出2024年低谷，但2025年初的增长主要是**恢复性反弹**，是否进入实质性结构转型（新兴产业替代、产业链延伸）**现有数据无法证实**。材料[1]所称“六大亮点”未展开，是下一步验证转型质量的关键信息缺口。
