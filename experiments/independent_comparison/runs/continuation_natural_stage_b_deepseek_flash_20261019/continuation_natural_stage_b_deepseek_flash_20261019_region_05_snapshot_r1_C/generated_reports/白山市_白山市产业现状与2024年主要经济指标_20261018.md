# 白山市 白山市产业现状与2024年主要经济指标产业研究报告

> 生成日期: 2026-10-18 18:45 UTC  
> 报告版本: 0.1.0

## 执行摘要

白山市产业处于资源型工业收缩、消费型轻工与服务业接棒的**结构转型攻坚期**，第三产业占比超六成但工业体量偏小，内生投资意愿持续走弱是最大风险。

**关键发现**

- **产业规模与地位**：2025年全市GDP 590.17亿元、增长5.6%，三次产业结构为12.8:24.7:62.5，第三产业绝对主导，第二产业占比不足四分之一，工业支撑力偏弱（注：2024年分项指标数据缺失，以2025年数据为分析主体）。

- **最突出优势**：酒饮料制造业增长33.6%、制造业整体增长19.2%、规上小型企业增长18.7%，消费型轻工与中小企业活力突出，高新技术企业达46户、当年新增13户，新动能初现成长期迹象。

- **最关键瓶颈**：固定资产投资下降10.2%、民间投资大幅下降37.4%，市场内生投资意愿弱；医药制造增速仅2.8%、采矿业下降1.7%、建筑业下降3.7%，传统动能收缩明显；税收收入仅15.33亿元，财政高增长主要靠非税拉动，可持续性存疑。

- **最紧迫行动**：遏制民间投资持续下滑态势，稳住转型期的市场信心与投资基本盘，同时推动医药制造提质升级、承接酒饮料成长期红利。

**决策建议**

1. **稳投资先稳预期**：针对民间投资下降37.4%的核心信号，梳理民间投资收缩的行业分布与堵点，出台针对性信心修复与项目对接机制。
2. **做强成长期赛道**：围绕酒饮料制造、消费型轻工等高增长行业，配套产业链下游品牌培育与出口能力建设，改变进出口总额仅11.91亿元与GDP规模不匹配的局面。
3. **补数据强监测**：2024年分项指标、龙头企业、园区集群等基础数据缺失，建议补充统计年鉴与工信、农业农村部门专项数据，为转型期精准决策提供依据。

## 1. 产业概况

### 1.1 产业规模

2025年白山市实现地区生产总值**590.17亿元**，比上年增长5.6%。三次产业增加值分别为：第一产业75.79亿元（增长4.9%）、第二产业145.58亿元（增长4.3%）、第三产业368.80亿元（增长6.2%）（材料[1]）。

- **农业**：农林牧渔业增加值77.85亿元，增长5.0%；粮食总产量32.05万吨，增长1.5%；猪牛羊禽肉类总产量3.61万吨（材料[1]）。
- **工业**：154户规模以上工业增加值增长11.4%，轻重工业比例46.1:53.9；建筑业增加值41.55亿元，下降3.7%（材料[1]）。
- **消费与外贸**：社会消费品零售总额110.50亿元，增长4.9%；进出口贸易总额11.91亿元，其中出口8.22亿元、进口3.69亿元（材料[1]）。

### 1.2 在经济中的地位

三次产业结构为**12.8:24.7:62.5**，第三产业占比超六成，是绝对主导；第二产业占比不足四分之一，工业体量偏小。地方级财政收入36.80亿元，增长53.2%，其中税收收入15.33亿元，增长7.1%——财政高增长主要非税拉动，税收支撑力有限（材料[1]）。

### 1.3 发展历程

材料未提供产业发展历程的系统数据，**关键节点数据缺失**。仅可从2021—2025年GDP增速、规上工业增加值增速、存贷款余额、人均可支配收入等图（图1—图6）判断"十四五"期间保持中速增长态势，具体节点无法从现有材料还原。

## 2. 产业链结构

白山市产业以**医药制造、酒饮料、有色金属矿采选、电力热力**为重点行业，呈"资源型+轻工消费型"双支柱格局（材料[1]）。

### 2.1 上游（原材料/种源/装备）

- **医药**：依托长白山中药材资源，但材料未披露中药材种植/采购规模，**数据缺失**。
- **有色金属矿采选**：2025年该行业增加值增长3.1%，属资源开采型上游环节（材料[1]）。
- **农业种源**：粮食种植面积69366.7公顷，谷物、豆类为主（豆类32162.8公顷），但加工转化数据缺失（材料[1]）。

### 2.2 中游（生产/加工）

- **医药制造业**增加值增长2.8%，增速在重点行业中偏低（材料[1]）。
- **酒、饮料制造业**增长33.6%，是增速最快的重点行业，轻工业增加值整体增长19.3%，显著高于重工业5.1%（材料[1]）。
- **制造业整体**增长19.2%，但采矿业下降1.7%，显示加工环节强于开采环节（材料[1]）。

### 2.3 下游（销售/出口/应用）

- 出口8.22亿元、进口3.69亿元，出口导向初显但总规模小（材料[1]）。
- 消费端：饮料类零售额增长44.6%、通讯器材增长30.6%、家电增长22.5%，与本地酒饮料产业形成一定呼应；但汽车类下降3.8%、中西药品下降8.6%（材料[1]）。

### 2.4 本县在产业链中的位置

**强项**：酒饮料制造（+33.6%）、制造业加工（+19.2%）、电力热力供应（+5.9%）。
**弱项**：医药制造增速仅2.8%、采矿业负增长、建筑业下降3.7%；产业链下游品牌与出口能力弱，进出口总额仅11.91亿元，与590亿元GDP不匹配（材料[1]）。

## 4. 发展阶段判断

**综合判断：白山市产业整体处于"转型期"，部分细分行业处于"成长期"。**

判断依据：

1. **结构转型特征明显**：第三产业占比62.5%，第二产业仅24.7%，且建筑业下降3.7%、采矿业下降1.7%，传统资源型工业收缩，服务业接棒（材料[1]）。
2. **新旧动能分化**：酒饮料（+33.6%）、制造业（+19.2%）、小型企业（+18.7%）高增长，而医药（+2.8%）、采矿（-1.7%）低迷，属典型转型期"冰火两重天"（材料[1]）。
3. **投资收缩警示**：固定资产投资下降10.2%，民间投资大幅下降37.4%，仅基础设施投资增长12.3%，说明市场内生投资意愿弱，转型动力更多依赖政府投资（材料[1]）。
4. **人口与财政约束**：常住人口87.53万人，自然增长率-8.16‰，人口持续流出；税收收入仅15.33亿元、财政增长靠非税，转型期财政支撑能力有限（材料[1]）。
5. **创新端初现成长期迹象**：高新技术企业达46户、当年新增13户，科技项目15项，创新主体处于成长期起步（材料[1]）。

**结论**：白山市产业不宜简单归为"成熟期"，而是**资源型工业收缩、消费型轻工与服务业成长、整体处于结构转型攻坚期**。建议重点关注酒饮料制造的成长期红利、医药制造的提质升级，以及民间投资持续下滑（-37.4%）这一核心风险信号。
