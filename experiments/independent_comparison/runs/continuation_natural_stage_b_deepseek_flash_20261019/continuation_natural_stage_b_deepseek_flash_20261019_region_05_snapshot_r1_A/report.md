# 白山市产业现状与2024年主要经济指标研究报告（snapshot）

**说明**：本报告严格依据所给资料撰写。资料[1]为白山市2024年统计公报（内容在“禽肉产量0.70”处截断），资料[2]为百度百科词条（正文内容未抓取到实质信息），资料[3]为**白城市**（非白山市）政府工作报告。凡资料未覆盖之处，均标注为资料缺口，不作推测性补数。


## 一、资料可用性评估（先行说明）

- **事实**：资料[1]标题为《白山市2024年国民经济和社会发展统计公报》，发文日期2025-08-06，来源为吉林省统计局网站（tjj.jl.gov.cn），可确认为白山市2024年主要经济指标的权威来源。[1]
- **事实**：资料[1]正文在“禽肉产量0.70”处中断，农业部分之后的工业、投资、消费、居民收入等章节缺失。[1]
- **事实**：资料[2]为百度百科“白山市”词条页面，抓取内容仅为导航框架，无实质正文。[2]
- **事实**：资料[3]为**白城市**人民政府工作报告，行政主体为白城市，与研究对象白山市不同，不能用于白山市指标。[3]
- **推断**：由于资料[1]截断、资料[2]无正文、资料[3]主体不符，本报告可支撑的内容集中于白山市2024年的GDP、产业结构、财政、物价与农业（部分），工业、服务业细分、投资、消费、收入等为资料缺口。


## 二、2024年主要经济指标（事实，来源[1]）

### 1. 地区生产总值
- **事实**：2024年白山市实现地区生产总值**567.85亿元**，比上年增长**3.4%**。[1]
- **事实**：第一产业增加值**72.80亿元**，增长**4.7%**；第二产业增加值**141.38亿元**，增长**0.2%**；第三产业增加值**353.67亿元**，增长**4.3%**。[1]
- **事实**：三次产业结构比重为**12.8∶24.9∶62.3**。[1]
- **推断**：第三产业占比超过六成，是白山经济的主体；第二产业增速仅0.2%，明显低于整体增速，是拖累全年增长的主要环节；第一产业增速最快但体量最小。

### 2. 物价
- **事实**：全市CPI同比增长**0.3%**，增幅较上年同期扩大0.3个百分点。[1]
- **事实**：分类看，其他用品和服务类增长3.4%，教育文化和娱乐类增长2.9%，医疗保健类增长1.3%，生活用品及服务类增长0.6%，居住类增长0.1%，衣着类持平，食品烟酒类下降0.1%，交通和通信类下降1.9%。[1]
- **推断**：CPI温和上涨，交通通信类价格下降，居民出行/通信成本压力减轻。

### 3. 财政
- **事实**：全口径财政收入**51.39亿元**，同比下降**8.5%**；其中市本级17.21亿元，下降26.1%。[1]
- **事实**：地方级财政收入**24.45亿元**，下降**11.1%**；税收收入**14.74亿元**，增长**5.8%**。[1]
- **事实**：财政支出**215.51亿元**，增长**21.9%**。其中一般公共服务支出18.20亿元（-3.6%）、卫生健康支出14.47亿元（+10.1%）、农林水支出30.92亿元（+58.4%）、社会保障和就业支出35.52亿元（+13.0%）、城乡社区支出12.23亿元（-25.2%）。[1]
- **推断**：财政收入端收缩（尤其市本级大幅下降）与支出端扩张并存，收支缺口扩大；税收收入逆势增长5.8%，说明收入下滑主要来自非税部分；农林水支出高增58.4%，与“两山”理念试验区、乡村振兴方向一致（此因果判断为推断）。

### 4. 农业（部分）
- **事实**：农林牧渔业增加值**74.72亿元**，增长**4.7%**。[1]
- **事实**：粮食种植面积69352.8公顷，比上年增加91.6公顷；其中稻谷352.0公顷（-35.0）、玉米35597.7公顷（-595.8）、豆类32634.9公顷（+808.4）。[1]
- **事实**：粮食总产量**31.57万吨**，下降**1.2%**；玉米23.62万吨（-2.8%）、水稻0.27万吨（-8.9%）、豆类7.35万吨（+5.9%），其中大豆6.74万吨（+4.0%）。[1]
- **事实**：猪牛羊禽肉类总产量3.59万吨，增长2.0%；猪肉1.93万吨（持平）、牛肉0.92万吨（+8.2%）、羊肉0.04万吨（持平）；禽肉产量数据在“0.70”处截断。[1]
- **推断**：种植结构呈“豆增玉米减”，与大豆扩种政策方向吻合（政策归因为推断）；粮食总产略降主要受玉米、水稻减产影响，豆类增产部分对冲。


## 三、产业现状（依据有限资料能作出的判断）

- **事实**：统计公报开篇提出白山“全面建设践行‘两山’理念试验区，大力实施‘一山两江’品牌战略，着力构建‘一体两翼’发展格局”。[1]
- **推断**：结合三次产业结构（三产62.3%、二产24.9%）与“两山”试验区定位，白山产业现状大体呈现“服务业主导、工业偏弱、农业特色化”的格局；但**资料未提供工业分行业、服务业分行业、旅游业、矿业（白山传统优势产业）等具体数据**，无法对支柱产业作量化描述。
- **资料缺口**：规模以上工业增加值及分行业数据、固定资产投资、社会消费品零售总额、进出口、居民人均可支配收入、旅游收入与人次、矿业/林业/医药等特色产业数据，均因资料[1]截断而缺失。


## 四、资料缺口与使用限制汇总

1. **资料[1]截断**：工业、投资、消费、收入、人口等章节缺失，无法覆盖“产业现状”的多数维度。[1]
2. **资料[2]无实质内容**：百度百科页面仅抓到导航框架，不能作为任何事实来源。[2]
3. **资料[3]主体错误**：系白城市（GDP增速6%、粮食118.45亿斤等）数据，**不可用于白山市**，本报告未采用其任何数字。[3]
4. **无法核验项**：公报中图1（2018—2024年GDP增速）、图2（三次产业结构图）为图片，正文未给出逐年数值，故2018—2023年增速序列为资料缺口。


## 五、结论（snapshot）

依据现有资料可确认：2024年白山市GDP为567.85亿元、增长3.4%，三次产业结构12.8∶24.9∶62.3，第三产业主导、第二产业近乎零增长；财政收支呈“收入降、支出增”的背离态势；农业种植结构“豆增粮减”；CPI温和上涨0.3%。受资料截断限制，工业、投资、消费、收入及特色产业细分数据无法呈现，构成后续研究的主要资料缺口。
