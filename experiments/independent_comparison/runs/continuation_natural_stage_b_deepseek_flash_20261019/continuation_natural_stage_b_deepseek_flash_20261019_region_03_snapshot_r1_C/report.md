# 于都县 于都县产业现状与2024年主要经济指标产业研究报告

> 生成日期: 2026-10-18 18:27 UTC  
> 报告版本: 0.1.0

## 执行摘要

于都县富硒农业已具备土壤资源与品牌基础，但产业链不完整、精深加工薄弱，整体处于"规划驱动型"成长期初期；2024年全县主要经济指标数据缺失，尚无法量化定位。

**关键发现**

- **产业规模与地位：** 富硒农业被定位为特色优势产业与乡村振兴抓手，但富硒产业总产值、占全县GDP比重及2024年GDP、规上工业、财政、社消等总量指标均数据缺失，产业贡献度无法量化评估。

- **最突出优势：** 拥有富硒土壤资源禀赋和较好农产品品牌基础，2025年5月完成2024—2031年富硒产业总体规划编制，确立"新长征，新硒望"区域品牌主题，产业从自发发展转入规划引领阶段。

- **最关键瓶颈：** 产业链中游精深加工与下游品牌溢价薄弱，规划自身将"农业产业链结构有待优化"列为关键问题，当前以初级农产品销售为主，加工转化率与龙头企业数据均未披露。

- **最紧迫行动：** 补齐2024年统计公报全文及富硒产业产值、加工转化率、龙头企业名录、园区入驻企业产值、从业人数等结构性数据，方能对产业阶段作出精确量化定位。

**决策建议**

- **优先补齐数据底座：** 以《于都县2024年国民经济和社会发展统计公报》及赣州市统计局县域数据为基础，建立富硒产业统计监测口径，明确产值、加工转化率、主体数量等核心指标，为后续决策提供量化依据。

- **聚焦补强加工与品牌两端：** 围绕规划确定的"三区三轴一核多点"布局，重点引进和培育精深加工主体，推动初级农产品向加工增值环节延伸，同步落地区域品牌与品牌矩阵体系，提升溢价能力。

- **以园区为载体推进集群化：** 依托种养殖标准化基地与农产品加工发展格局，明确园区入驻标准与产值目标，推动经营主体从分散发展向集群集聚过渡，加速成长期向成熟期迈进。

## 一、产业现状分析

# 于都县产业现状与2024年主要经济指标分析

> 说明：本次采集到的有效材料仅为《于都县富硒产业发展总体规划（2024—2031）》（材料[1]）及被截断的国家统计公报（材料[2]）。材料[1]为规划文本，侧重富硒农业，对2024年全县GDP、规上工业、财政、社消等主要经济指标的完整数据未予披露；材料[2]内容截断，无法提供于都县本级数据。因此，本报告以富硒农业及关联产业为主线展开，凡涉及全县总量指标处均标注"数据缺失"，不做推测。


## 1. 产业概况

**产业规模。** 于都县农业以种植业、养殖业为主体，富硒农业为特色主导方向。材料[1]显示，项目区已形成较好的农产品品牌基础，富硒土壤资源与产业发展"取得成效"，但规划文本未给出全县富硒产业总产值、富硒农产品产量、从业人数的具体数值，**相关规模数据缺失**。规划提出的区域品牌主题语为"新长征，新硒望"，品牌名称与视觉识别系统（VIS）在文本中列有专节（5.1节），表明品牌建设尚处于策划落地阶段。

**在全县经济中的地位。** 材料[1]第3.3节判断于都"经济发展稳健增长，处于中等偏上国家水平""三产结构合理、城乡收入差距缩小"，说明县域经济整体已进入工业化与城镇化协同推进阶段，农业在GDP中的比重趋于下降，但富硒农业被定位为特色优势产业与乡村振兴抓手。**富硒产业占全县GDP比重、对财政贡献度等量化数据缺失。**

**发展历程。** 可辨识的关键节点为：2024—2031年富硒产业发展总体规划启动编制；2025年5月由北京东方畅想建筑设计有限公司与中国农业大学联合完成规划文本（规划主持人赵桂慎），委托单位为于都县农业农村局。这标志于都富硒产业从分散发展转入"规划引领、品牌统摄"的新阶段。更早期的产业起步节点，现有材料未载明。

**2024年主要经济指标。** 全县地区生产总值、规上工业增加值、固定资产投资、社会消费品零售总额、一般公共预算收入、城乡居民人均可支配收入等**均数据缺失**，建议后续以《于都县2024年国民经济和社会发展统计公报》及赣州市统计局县域数据补齐。


## 2. 产业链结构

**上游（种源/土壤/装备）。** 于都的核心禀赋是富硒土壤资源（材料[1]第3.5.1节"富硒土壤与产业发展成效"）。规划强调种养殖业标准化建设基地，并设"种养殖业标准化建设基地"专节（6.5节），说明上游正从自然禀赋依赖转向标准化基地支撑。但**富硒种源（专用品种）、肥料、农机装备等上游环节的本地供给能力，材料未展开，数据缺失。**

**中游（生产/加工）。** 材料[1]明确指出"农业产业链结构有待优化"（3.4.6节），并单列"农产品加工发展格局"（6.6节），反映当前加工环节是短板——以初级农产品销售为主，精深加工不足。规划提出构建"产业生态链"、明确主导产业与产业链构建（6.2节），并布局"三区三轴一核多点"空间结构（6.3节），意在补强加工与集群环节。

**下游（销售/品牌/融合）。** 下游以区域品牌为统领，规划设计了"区域品牌+品牌矩阵体系"（5.1、5.2节），主题语"新长征，新硒望"融合红色文化IP；同时规划强调一二三产融合是乡村产业发展方向（2.1.4节），指向农旅、康养等延伸应用。

**本县在产业链中的位置。** 强项在**上游资源端（富硒土壤）与种植养殖基地**；弱项在**中游精深加工与下游品牌溢价**——规划自身将"产业链结构有待优化"列为关键问题，是本县最需补强的环节。


## 3. 市场主体

**龙头企业。** 材料[1]第3.5.2节设有"农业经营主体调研分析"，表明规划编制方对县域经营主体做过专项调研，但**文本未列出龙头企业具体名称、产值规模与特色产品，数据缺失。**

**中小企业与合作社。** 同上，调研已开展但数量、结构数据在现有材料中未披露，**数据缺失**。

**产业集群/园区。** 规划提出"三区、三轴、一核、多点"的功能分区与空间布局（6.3节），并布局种养殖标准化基地与农产品加工发展格局，指向以园区/基地为载体推进集群化。但园区名称、入驻企业数、产值等**具体数据缺失**。


## 4. 发展阶段判断

**判断：于都富硒产业整体处于"成长期初期"，并带有明显的"规划驱动型转型"特征。**

判断依据：

1. **资源与品牌基础已具备，但产业链不完整。** 材料[1]确认富硒土壤与产业发展"取得成效"、农产品品牌基础较好，说明已完成从无到有的起步；但"农业产业链结构有待优化"被列为关键问题，加工与品牌溢价环节薄弱，符合成长期初期特征。
2. **刚刚完成系统性规划供给。** 2024—2031年总体规划于2025年5月编制完成，品牌名称、VIS、空间布局、产业生态链等尚在落地阶段，说明产业正从自发发展转向有组织推进，属于成长期起步的典型信号。
3. **经营主体已有调研基础但尚未形成集群数据。** 规划对经营主体开展专项调研、对富硒认知度开展调查（3.5.3节），反映主体数量与市场认知仍在培育中，未达成熟期的稳定格局。
4. **尚未进入成熟期或转型期。** 成熟期应以加工增值占比高、品牌溢价稳定、集群效应显著为标志，现有材料均未提供此类证据；转型期通常表现为传统产业衰退后的结构再造，与于都当前"增量扩张+规划引领"的态势不符。

**建议关注：** 后续应重点补齐2024年全县GDP、规上工业、财政收入等总量指标，以及富硒产业产值、加工转化率、龙头企业名单等结构性数据，方能对成长期阶段作出更精确的量化定位。


**数据缺口清单（需补充采集）：** ①于都县2024年统计公报全文；②富硒产业总产值及占农业总产值比重；③农产品加工转化率；④龙头企业与合作社名录及数量；⑤园区/集群入驻企业与产值；⑥富硒产业从业人数。
