# 临泽县产业现状与2024年主要经济指标研究报告（Snapshot）

**研究说明**：本报告仅依据所给资料撰写。资料[1]为临泽县2024年统计公报的**部分内容**（截断于畜牧业部分），资料[2]为人口库页面（含2025年及2024年部分数据），资料[5]为2026年1月发布的"十四五"综述。资料[3][4]分别为国家层面和安远县的政府工作报告，**与临泽县无直接关系**，本报告不将其作为临泽县事实依据。凡资料未覆盖者，一律列入资料缺口，不作推测填补。


## 一、人口与城镇化（2024年末）

**事实：**
- 2024年末总人口145854人，比上年减少591人；常住人口11.16万人。[1]
- 常住人口中城镇人口5.78万人，常住人口城镇化率51.83%，比上年末提高1.33个百分点。[1]
- 全年出生人口700人，出生率6.36‰；死亡人口1100人，死亡率9.78‰；自然增长率-3.42‰。[1]
- 城镇新增就业2436人，702名高校毕业生实现就业，城镇登记失业率控制在4.5%以内；年内输转劳动力2.83万人（其中有组织输出2.1万人），实现劳务收入8.72亿元，增长0.8%。[1]

**推断：**
- 总人口（145854人）与常住人口（11.16万人）差额约3.4万人，可推断为外出流动人口规模较大，属人口净流出县；自然增长率为负，人口总量呈收缩态势。[1]
- 城镇化率年提高1.33个百分点，在人口负增长背景下，推断城镇人口增长主要来自乡村人口转移而非自然增长。[1]

**资料缺口：**
- 2024年GDP总量、三次产业结构、人均GDP、财政收入、城乡居民可支配收入等核心经济指标，所给资料[1]未包含（页面在畜牧业处截断）。
- 资料[2]所列"2025年GDP 87.92亿元、2025年城镇/农村居民可支配收入36898元/25256元"为**2025年数据**，不能用于2024年指标；且该页为第三方汇总页，非原始公报，本报告仅作参考标注，不作为2024年事实引用。


## 二、农业与主导产业

**事实：**
- 全年农林牧渔业增加值28.71亿元，增长7.46%。[1]
- 农作物总播种面积53.61万亩，增长3.75%；粮食作物37.65万亩（增长1.94%），其中小麦1.45万亩、玉米35.67万亩；玉米中**制种面积31.82万亩**，增加2.34万亩；蔬菜面积9.02万亩。[1]
- 粮食总产量18.25万吨，增长2.54%（夏粮0.8万吨、秋粮17.45万吨）；小麦产量0.78万吨，玉米产量17.34万吨；蔬菜总产量30.09万吨，增长6.6%。[1]
- 林业：完成三北防护林等生态工程7448亩，补播改良退化草原1万亩，新建草原围栏20公里；建成区绿化覆盖率45.99%，绿地率41.45%，人均公园绿地16.83平方米；建成数字化林果基地551亩，发展木本油料等特色经济林3010亩。[1]
- 畜牧业：落实草原禁牧面积73.63万亩，草原综合植被覆盖度30.83%，秸秆饲料化利用率85.1%；累计建成标准化养殖场（区）174个（原文在此截断）。[1]
- "十四五"综述称：全县玉米制种面积持续稳定在30万亩以上，年产优质种子约1.5亿公斤；采用"企业＋基地＋农户"模式，实现全程机械化与标准化生产。[5]

**推断：**
- 制种玉米面积（31.82万亩）占玉米面积（35.67万亩）约89%、占粮食作物面积约85%，可推断**玉米制种是临泽农业的第一支柱**，农业结构高度集中于制种产业。[1]
- 农林牧渔业增加值增速（7.46%）明显高于粮食产量增速（2.54%），推断增长主要来自蔬菜（产量增6.6%）、畜牧业及林业经济业态等非粮板块。[1]
- 制种面积一年增加2.34万亩，结合[5]"稳定在30万亩以上"的表述，推断该产业仍处于扩张或高位稳固阶段。[1][5]

**资料缺口：**
- 畜牧业产值、存出栏量等具体数据（原文截断）。[1]
- 制种产业产值、种子企业数量、制种收入占农民收入比重。[1][5]均未给出。
- 工业、服务业、固定资产投资、社会消费品零售总额、财政、金融、居民收入等**全部二、三产业指标**，所给资料均缺失。


## 三、产业总体格局（基于有限资料的谨慎判断）

**推断（非事实）：**
- 从可得资料看，临泽县产业结构呈现"**农业强、制种主导**"的特征：农林牧渔业增加值28.71亿元，制种玉米占据粮食生产的绝对主体地位。[1]
- [5]提到临泽连续三年获评"全省县域经济发展先进县"，跻身全省县域综合竞争力与产业发展竞争力"十强"，并提及"一核四廊多点"空间布局和"一城五县"建设目标——但该文**未给出任何2024年具体经济指标数值**，仅可推断其县域经济在甘肃省内评价体系中表现较好。[5]

**资料缺口（关键）：**
- 2024年GDP、规上工业增加值、固定资产投资、社零总额、一般公共预算收入、城乡居民人均可支配收入等**均无来源**，无法构建完整的2024年经济指标表。
- 工业主导产业（除农产品加工外）、文旅产业、新能源等产业现状无资料支撑。
- [5]为2026年发布的综述性报道，属二手宣传材料，其定性表述（"持续稳步增长""显著增强"）无具体数字佐证，不宜作为量化依据。


## 四、结论与资料评价

1. **可确认的2024年核心事实**集中在人口、就业、农业（尤其制种玉米）领域，来源为临泽县统计局公报[1]。
2. **2024年主要经济指标（GDP及二、三产业）在本批资料中系统性缺失**，所给公报[1]仅为节选，无法支撑"主要经济指标"全景式snapshot。
3. 资料[2]含2025年GDP与收入数据，但年份不符且为第三方页面；资料[3][4]与临泽无关；资料[5]为定性综述。三者均不能替代2024年原始公报。
4. **建议补充**：临泽县2024年统计公报全文（含GDP、三次产业、投资、消费、财政、收入各表），以及临泽县2024年政府工作报告，方可完成完整的指标snapshot。
