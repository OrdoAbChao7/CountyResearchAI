# 白山市产业现状与2024年主要经济指标研究报告（snapshot 模式）

**说明**：本报告仅依据所给资料[1]—[4]撰写。资料[1]为吉林省统计局网站转载的《白山市2024年国民经济和社会发展统计公报》页面（内容在"农业"部分禽肉产量处截断）；资料[4]为红黑统计公报库转载的同一公报（同样在农业部分截断，但补充了完整的CPI表）；资料[2]为百度百科词条页面（正文内容在抓取中基本缺失）；资料[3]为2026年3月发布的省级专题报道，属"十五五"开局视角的产业综述，非2024年统计口径。凡资料未覆盖处，均标注为资料缺口，不作推测性补数。

---

## 一、2024年主要经济指标（事实，来源[1][4]）

### 1. 地区生产总值（GDP）

- 2024年白山市实现地区生产总值 **567.85亿元**，比上年增长 **3.4%**（来源[1]）。
- 分产业：第一产业增加值 **72.80亿元**，增长 **4.7%**；第二产业增加值 **141.38亿元**，增长 **0.2%**；第三产业增加值 **353.67亿元**，增长 **4.3%**（来源[1]）。
- 三次产业结构比重为 **12.8 : 24.9 : 62.3**（来源[1]）。

**推断**：第三产业占比超过六成、增速（4.3%）高于整体（3.4%），是拉动增长的主要力量；第二产业增速仅0.2%，接近零增长，工业端对增长的贡献明显偏弱。此推断仅基于上述增速与结构数据，资料未给出各产业对增长的贡献率分解。

### 2. 价格指数（CPI）

- 2024年全市CPI同比上涨 **0.3%**，增幅较上年同期扩大0.3个百分点（来源[1][4]）。
- 分类别看：其他用品和服务类上涨3.4%，教育文化和娱乐类上涨2.9%，医疗保健类上涨1.3%，生活用品及服务类上涨0.6%，居住类上涨0.1%；衣着类持平；食品烟酒类下降0.1%，交通和通信类下降1.9%（来源[1][4]）。
- 资料[4]的完整表1显示居民消费价格总指数为 **100.3**（上年=100）（来源[4]）。

### 3. 财政收支

- 全口径财政收入 **51.39亿元**，同比下降 **8.5%**；其中市本级全口径财政收入 **17.21亿元**，下降 **26.1%**（来源[1][4]）。
- 地方级财政收入 **24.45亿元**，下降 **11.1%**；税收收入 **14.74亿元**，增长 **5.8%**（来源[1][4]）。
- 财政支出 **215.51亿元**，增长 **21.9%**。主要支出项：一般公共服务支出18.20亿元（-3.6%）；卫生健康支出14.47亿元（+10.1%）；农林水支出30.92亿元（+58.4%）；社会保障和就业支出35.52亿元（+13.0%）；城乡社区支出12.23亿元（-25.2%）（来源[1][4]）。

**推断**：收入端（全口径-8.5%、地方级-11.1%）与支出端（+21.9%）走势相反，收支缺口扩大；税收收入逆势增长5.8%而全口径收入下降，说明非税部分或上级分成口径的收入下滑明显。资料未披露非税收入细项，此推断的机制部分属资料缺口。

### 4. 农业（资料覆盖范围内）

- 农林牧渔业增加值 **74.72亿元**，增长 **4.7%**（来源[1][4]）。
- 粮食种植面积 **69352.8公顷**，比上年增加91.6公顷；其中稻谷352.0公顷（-35.0公顷）、玉米35597.7公顷（-595.8公顷）、豆类32634.9公顷（+808.4公顷）（来源[1][4]）。
- 粮食总产量 **31.57万吨**，下降 **1.2%**；玉米23.62万吨（-2.8%）、水稻0.27万吨（-8.9%）、豆类7.35万吨（+5.9%），其中大豆6.74万吨（+4.0%）（来源[1][4]）。
- 猪牛羊禽肉类总产量 **3.59万吨**，增长 **2.0%**；猪肉1.93万吨（持平）、牛肉0.92万吨（+8.2%）、羊肉0.04万吨（持平）；禽肉产量数据在"0.70"处截断（来源[1][4]）。

**推断**：种植结构呈"玉米减、豆类增"的调整态势，与粮食总产小幅下降相吻合；豆类扩种未能完全抵消玉米减产。此推断基于面积与产量数据的方向一致性，属分析性判断。

## 二、产业现状（依据资料[3]，注意口径）

资料[3]为2026年3月发布的"十五五"专题报道，其数据多为2025年或规划性表述，**不能直接作为2024年指标**，仅可用于描述产业格局与方向：

- **传统产业**：煤、林、铁等传统产业推进"焕新"；白山市被表述为"依靠资源兴起的老工业城市"，处于绿色转型关键时期（来源[3]）。
- **优势产业**：文化旅游、医药健康、绿色食品、清洁能源、新材料等加速"跃升"；同时布局北斗卫星、低空经济等新兴产业和未来产业（来源[3]）。
- **文旅**：森林覆盖率居全国地级市首位（资料表述），地处北纬41度冰雪黄金纬度带；春节假期接待国内游客同比增长31%、出游花费同比增长24%（该数据对应资料[3]发布时点的当年春节，非2024年全年）；沈白高铁与G331沿边开放旅游大通道"双线贯通"（来源[3]）。
- **人参产业**：构建"7+3"产业体系，开发五大系列830余款产品；**2025年**人参全产业链产值达263.2亿元，"抚松人参"获评中国品牌价值榜第37名（来源[3]）。
- **矿泉饮品**：全市矿泉水企业49户，矿泉水产能、产量、产值均占全省80%以上（来源[3]）。
- **松花石**：组建"松花石产业联盟（江源）"，探索"松花石+文创"路径（来源[3]，正文在"从事松花石生产加工、经营销售及配"处截断）。

**资料缺口**：资料[1][4]的公报正文在农业部分即截断，**未覆盖**工业、固定资产投资、社会消费品零售总额、进出口、居民收入、规上工业增加值、主要工业产品产量、旅游总人次与总收入等2024年关键指标；资料[2]（百度百科）正文未抓取到有效内容，无法用于核实市情基础数据（面积、人口、行政区划等）。因此，2024年白山市工业与服务业分行业现状、投资消费数据均无法在本资料集内给出，属明确缺口。
