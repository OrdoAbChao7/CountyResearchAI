# 于都县 于都县产业现状与2024年主要经济指标产业研究报告

> 生成日期: 2026-10-18 19:24 UTC  
> 报告版本: 0.1.0

## 执行摘要

于都县产业正处于工业化驱动的成长期，制造业与红色文旅双轮驱动，但第三产业增速偏低与投资信心不足构成主要制约。

**关键发现**

- **产业规模与地位**：2024年GDP达352.61亿元（+4.9%），三次产业结构为10.6:32.6:56.8，第三产业占比最高但增速仅3.0%，低于GDP增速，是拖累整体增长的主要因素；第二产业增速8.6%，工业占GDP比重提升至26.9%，工业化进程明显加速。

- **最突出优势**：红色文旅品牌效应突出，全年接待游客1680.8万人次（+9.7%），红色旅游占比近七成（1155.9万人次、收入96.12亿元），已成为于都最具辨识度的产业名片；规上工业增加值增长13.8%、产销率98.1%，制造业加工环节基础扎实。

- **最关键瓶颈**：民间投资下降16.2%、实际利用外资骤降51.7%，市场化主体扩张意愿偏弱；住宿业零售额仅2.78亿元，文旅"过境地"特征明显，接待规模与本地消费转化不匹配；一产投资下降53.1%，农业后续动能存忧。

- **最紧迫行动**：需着力扭转投资信心不足局面，同时补齐文旅消费转化短板，将游客流量转化为本地消费增量。

**决策建议**

1. **稳投资、提信心**：针对民间投资与外资大幅下滑，系统梳理民间投资堵点，优化营商环境，遏制投资收缩趋势。
2. **强文旅、促转化**：围绕红色文旅流量优势，重点补齐住宿、餐饮、消费场景等留客环节，推动"过境地"向"目的地"转变。
3. **补数据、明底数**：龙头企业、园区经济、制造业细分构成等关键数据缺失，建议尽快补充统计年鉴细分表与园区、市场监管部门数据，为精准决策提供依据。

## 一、产业现状分析

# 于都县产业现状与2024年主要经济指标分析

> 数据采集日期：2026-10-18；主要数据来源：于都县2024年国民经济和社会发展统计公报（材料[2]）、于都县政府信息公开GDP数据（材料[1]）。部分指标两源存在口径差异，已交叉标注。


## 1. 产业概况

### 1.1 产业规模

2024年于都县地区生产总值**352.61亿元**，按不变价格计算同比增长**4.9%**（材料[1]）。三次产业增加值分别为：第一产业37.29亿元（+3.6%）、第二产业115.03亿元（+8.6%）、第三产业200.29亿元（+3.0%）（材料[1]）。三次产业结构为**10.6:32.6:56.8**（据材料[1]数据计算；2023年修订后基数为10.3:31.8:57.9）。

工业方面，2024年全县工业增加值**94.785亿元**，增长9.7%，占GDP比重26.9%，较上年提升0.9个百分点；规模以上工业增加值增长**13.8%**，规上工业总产值**209.08亿元**（+11.7%），规上工业营业收入**207.03亿元**（+7.9%）（材料[2]）。建筑业总产值52.93亿元（+12.6%），资质等级建筑企业60家（材料[2]）。

农业方面，粮食总产量24.24万吨（+5.2%），蔬菜34.99万吨（+6.0%），脐橙10.72万吨（持平），肉类总产量9.48万吨（-0.3%）（材料[2]表1、表2）。

服务业方面，服务业增加值200.29亿元（+3.0%）；社会消费品零售总额154.85亿元（+5.8%），其中限上零售额33.55亿元（+13.9%）（材料[2]）。

### 1.2 在经济中的地位与贡献

- **第三产业主导**：占比56.8%，但增速仅3.0%，低于GDP增速，是拖累整体增长的主要因素；其中房地产业增加值下降2.1%（材料[2]）。
- **第二产业是增长引擎**：增速8.6%，规上工业增加值增长13.8%，工业占GDP比重提升0.9个百分点，显示工业化进程加速（材料[2]）。
- **第一产业基础稳固但投资大幅收缩**：一产投资下降53.1%，占全部投资仅2.1%（材料[2]），农业后续增长动能存忧。
- **旅游是突出亮点**：全年接待游客1680.8万人次（+9.7%），旅游综合收入159.58亿元（+11.7%）；其中红色旅游接待1155.9万人次（+16.1%），红色旅游收入96.12亿元（+14.2%）（材料[2]），红色文旅已成为于都最具辨识度的产业名片。

### 1.3 发展历程（关键节点）

材料未提供完整产业沿革数据，据现有信息可识别以下节点：2023年GDP修订为340.03亿元（五经普修订，材料[1]）；2024年GDP达352.61亿元、工业占比提升至26.9%（材料[2]）；长征源合唱团累计完成669场公益巡演（材料[2]），反映红色文旅品牌持续运营。更早的产业演进节点**数据缺失**。


## 2. 产业链结构

> 说明：材料未按细分产业提供完整产业链数据，以下基于统计公报可辨识的行业分类作框架性分析，具体环节企业构成**数据缺失**。

### 2.1 工业产业链

- **上游（采矿/原材料）**：采矿业规上营业收入17.01亿元（+7.6%）（材料[2]），占规上工业营收约8.2%，表明本地矿产资源开采具备一定基础。
- **中游（制造/加工）**：制造业规上营业收入185.32亿元（+8.1%）（材料[2]），占规上工业营收**89.5%**，是工业绝对主体；但公报未披露制造业细分行业构成，主导产业（如纺织服装、电子信息等）**数据缺失**。
- **下游（销售/出口）**：规上工业销售产值205.12亿元（+11.8%），产销率98.1%（材料[2]）；实际利用外资仅410万美元，下降51.7%（材料[2]），出口与外资拉动弱。
- **配套（电力热力燃气水）**：营业收入4.70亿元（+3.4%）（材料[2]），占2.3%，能源配套规模较小。

**强弱项判断**：强项在制造业加工环节（占营收近九成、产销率98.1%）；弱项在上游本地配套与下游外向型销售（外资骤降51.7%），产业链外向度与附加值环节**数据缺失**，难以评估。

### 2.2 农业产业链

上游以种养为主（粮食、蔬菜、脐橙、生猪），中游加工环节数据**缺失**；下游依托脐橙（10.72万吨）等特色农产品，但品牌与加工转化率**数据缺失**。蔬菜产量34.99万吨（+6.0%）显示规模化种植扩张较快（材料[2]）。

### 2.3 文旅产业链

以红色旅游为核心（接待1155.9万人次、收入96.12亿元，材料[2]），下游消费端表现强劲；但住宿业零售额仅2.78亿元（+23.5%）、餐饮业28.02亿元（+5.7%）（材料[2]），接待规模与本地消费转化不匹配，说明"过境地"特征明显、留客消费环节偏弱。


## 3. 市场主体

### 3.1 龙头企业

统计公报**未披露具体龙头企业名称与规模**，此项**数据缺失**。可间接观察：规上工业企业营收207.03亿元、利税总额17.35亿元（+3.8%）（材料[2]），但企业数量未公布，单体规模无法测算。

### 3.2 中小企业与合作社

- 资质等级建筑企业60家（材料[2]）；
- 规上服务业企业营业收入18.16亿元（+11.4%）（材料[2]），企业数量**数据缺失**；
- 农民合作社、中小企业总数**数据缺失**。

### 3.3 产业集群/园区

公报未披露工业园区名称、入驻企业数、园区产值等**数据缺失**。可参考的集群化线索：制造业营收占规上工业89.5%（材料[2]），但空间集聚形态无法从现有材料确认。


## 4. 发展阶段判断

### 判断结论：整体处于**成长期**，其中红色文旅处于**成长期向成熟期过渡**，房地产业处于**调整/转型期**。

### 判断依据

1. **工业高速扩张**：规上工业增加值增长13.8%、工业占GDP比重提升0.9个百分点、二产投资增长15.7%（材料[2]），符合成长期"工业化率上升、投资扩张"特征。
2. **民间投资信心不足**：民间投资下降16.2%、实际利用外资下降51.7%（材料[2]），显示成长期内部结构不稳，市场化主体扩张意愿偏弱，是成长期中的风险信号。
3. **文旅品牌成熟度较高**：游客与收入双位数增长、红色旅游占比近七成（材料[2]），品牌（长征源）已形成，但住宿消费转化弱，处于成长期后段。
4. **房地产进入调整期**：房地产业增加值-2.1%、商品房销售面积-11.5%、销售额-13.6%（材料[2]），明确处于转型/下行调整阶段。
5. **人口与城镇化支撑**：常住人口89.96万人、城镇化率47.38%（+0.74个百分点）（材料[2]），城镇化仍有空间，为成长期提供需求支撑；但常住人口减少4218人，长期需警惕。

**综合判断**：于都县产业整体处于工业化驱动的成长期，增长动能主要来自制造业与红色文旅；主要短板是第三产业增速偏低（3.0%）、民间投资收缩、外资大幅下滑，以及产业链细分数据不透明导致的结构性风险难以量化评估。


**数据缺口提示**：本分析中龙头企业名单、园区经济指标、制造业细分行业构成、中小企业与合作社数量、农业加工转化率等关键数据在参考材料中均缺失，建议补充统计年鉴细分表、工业园区管委会数据及市场监管部门市场主体登记数据后进一步完善。
