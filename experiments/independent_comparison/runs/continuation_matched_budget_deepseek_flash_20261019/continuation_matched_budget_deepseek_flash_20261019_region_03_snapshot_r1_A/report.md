# 于都县产业现状与2024年主要经济指标研究报告（snapshot）

**说明**：本报告仅依据所给三份资料撰写。资料[1]为2024年统计公报（页面内容不完整，仅含农业、畜牧及工业部分段落）；资料[2]为2025年统计公报（含2025年数据及与2024年的结构对比）；资料[3]为于都县政府信息公开"统计信息"栏目页，仅显示导航结构，无具体统计数据。凡资料未载明者，一律列为资料缺口，不作推算或补填。

---

## 一、2024年主要经济指标

### （一）可确认的事实

1. **工业增加值**：2024年全县实现工业增加值947850万元（约94.79亿元），较上年增长9.7%，占全县GDP比重26.9%，较上年提升0.9个百分点。[来源：资料1，"三、工业和建筑业"段]
2. **规模以上工业**：2024年规模以上工业增加值增长13.8%；规模以上工业总产值2090798万元（约209.08亿元），比上年增长11.7%；销售产值2051235万元（约205.12亿元），增长11.8%；工业产销率98.1%；规模以上工业营业收入207.03亿元。[来源：资料1，同上段]
3. **产业结构（由2025年公报回溯）**：2025年公报称三次产业结构"由去年同期的10.6:32.4:57.0调整为10:32.4:57.6"，其中"去年同期"即2024年，故2024年三次产业结构为**10.6:32.4:57.0**。[来源：资料2，GDP段]
4. **农业（2024年）**：粮食总产量242403吨，增长5.2%；花生19416吨，下降1.0%；油菜籽5887吨，增长3.9%；芝麻125吨，增长2.5%；甘蔗953吨，增长2.7%；蔬菜349941吨，增长6.0%；瓜果13187吨，增长6.1%；水果138843吨，增长1.0%；其中脐橙107244吨，与上年持平（增长0）。[来源：资料1，表1]
5. **畜牧业（2024年）**：肉类总产量94833吨，下降0.3%；猪肉38421吨，增长6.0%；禽蛋5026吨，增长2.3%；生猪存栏258678头，增长11.5%；家禽存笼124428百只，下降3.0%；大牲畜（牛）存栏22889头，增长2.0%。[来源：资料1，表2]

### （二）推断（非直接记载）

1. 由工业增加值947850万元、占GDP比重26.9%，可推算2024年GDP约为 **352.4亿元**（947850÷26.9%）。此为推算值，资料未直接给出2024年GDP，**不应作为公报原始数据引用**。
2. 由2024年产业结构10.6:32.4:57.0与上述推算GDP，可粗略推算三次产业增加值量级，但属二次推算，误差随推算链放大，仅作参考。
3. 规模以上工业总产值增速（11.7%）高于增加值增速（13.8%为增加值，二者口径不同），不宜直接比较；可推断工业增长主要由规上工业带动，但资料未给出规下工业数据，无法验证。

### （三）资料缺口

- 2024年**地区生产总值（GDP）总量、增速、人均GDP**：资料1页面在工业段后即中断，未见GDP段落；资料2仅给出2025年GDP及2024年结构比例，未给2024年GDP绝对值。
- 2024年**财政总收入、一般公共预算收入、税收收入、财政支出**及分项支出：资料1未见；资料2仅有2025年数据。
- 2024年**第一产业、第二产业、第三产业增加值**绝对值及贡献率：仅有结构比例，无绝对值。
- 2024年**农林牧渔业总产值**、粮食播种面积：资料1表1仅有产量，无产值与面积；资料2的2025年数据不能替代。
- 2024年**固定资产投资、社会消费品零售总额、进出口、居民收入、人口**等指标：三份资料均未载明。
- 2024年**工业分行业结构**（如纺织服装、电子信息等主导产业占比）：资料1仅给总量，未给行业细分，无法判断"产业现状"的行业构成。

## 二、产业现状（基于资料可判断的部分）

### （一）事实

1. **产业结构以第三产业为主**：2024年三次产业结构10.6:32.4:57.0，第三产业占比57.0%，第二产业32.4%，第一产业10.6%。[来源：资料2，GDP段回溯]
2. **工业地位上升**：2024年工业增加值占GDP比重26.9%，较上年提升0.9个百分点；规上工业增加值增长13.8%，高于工业整体增速9.7%。[来源：资料1]
3. **农业以粮食、蔬菜、水果（脐橙）为大宗**：2024年粮食产量24.24万吨、蔬菜34.99万吨、水果13.88万吨（其中脐橙10.72万吨）；畜牧业以生猪为主，生猪存栏25.87万头。[来源：资料1，表1、表2]
4. **2025年延续态势（供参照，非2024年数据）**：2025年GDP 3760419万元、增长6%；三次产业结构10:32.4:57.6；规上工业未在资料2可见段落中列明；农业方面粮食251701.5吨、蔬菜369444.5吨、水果165271吨、脐橙106486吨、肉类85983.4吨、生猪存栏236632头。[来源：资料2]

### （二）推断

1. 于都县经济结构已呈"三二一"格局，第三产业贡献率在2025年为56.6%（资料2），可推断2024年第三产业亦为增长主引擎，但2024年贡献率资料未载明，不能直接引用2025年数值替代。
2. 工业中规上工业增速（13.8%）显著高于工业整体（9.7%），可推断规上企业是工业增长主要来源；但规下工业是否收缩，资料不足，不能断言。
3. 脐橙产量2024年与上年持平、2025年略降至106486吨，可推断水果产业进入平稳期；但缺乏价格、产值数据，无法判断效益变化。

### （三）资料缺口

- **主导产业/产业集群的具体构成**（如纺织服装、电子信息、装备制造等）及其产值占比：三份资料均未提供行业分类数据，无法描述"产业现状"的行业结构。
- **规模以上工业企业数量、企业效益（利润总额）**：资料1仅有营业收入207.03亿元，无利润、无企业数。
- **园区经济、招商引资、工业投资**：均无资料。
- **第三产业内部结构**（批零住餐、金融、文旅等）：仅有总量占比，无细分。
- **农业产业化、农产品加工产值**：无资料。

## 三、结论与使用建议

1. **可直接引用的事实**：2024年工业增加值94.79亿元、增长9.7%、占GDP 26.9%；规上工业总产值209.08亿元、增长11.7%、产销率98.1%、营业收入207.03亿元；2024年三次产业结构10.6:32.4:57.0；2024年主要农产品与畜牧产量（见表1、表2）。以上均出自资料1、资料2，来源明确。
2. **需标注为推算**：2024年GDP约352.4亿元（由工业增加值占比反推），不宜作为公报数据直接引用。
3. **主要缺口**：2024年GDP绝对值与增速、财政收支、投资消费、居民收入、人口、工业行业结构等均缺，建议以于都县政府网"统计信息"栏目（资料3所示入口）或赣州市统计局原文补齐后再作完整产业分析。
4. **时效提示**：资料2为2025年公报（页面标注发布于2026-08-15），其数据属2025年，本报告仅在回溯2024年结构比例时使用，未将其混作2024年指标。
