# 攀枝花市 攀枝花市产业现状与2024年主要经济指标产业研究报告

> 生成日期: 2026-10-18 19:33 UTC  
> 报告版本: 0.1.0

## 执行摘要

攀枝花产业处于“资源型成熟产业支撑、新旧动能转换攻坚”的转型期，核心任务是延长钒钛链条、提升就地转化率、培育增量产业。

- **产业规模与地位**：2025年前三季度GDP达1058.57亿元、增长4.5%，二产占比约55.3%，工业主导型经济特征显著，但增速低于全国1.7个、全省2.6个百分点，增长承压明显。
- **最突出优势**：钒钛磁铁矿资源全国独有，上游采选与中游钒钛初级加工基础雄厚，“十三五”期间钒钛占工业比重由5.3%升至17.2%，国产EB炉、氯化钛白等深加工实现突破。
- **最关键瓶颈**：产业链仍处前端，资源就地加工转化率不高，产业结构和企业结构单一，中小企业集群支撑不足，新兴产业发育缓慢，新旧动能转换尚未完成。
- **最紧迫行动**：以“1+3+3”现代工业体系为框架，主攻钒钛深加工与终端应用延伸，同步布局新能源、电子信息等非资源型增量产业，提升园区集聚承载能力。

**决策建议**

1. **补链强链**：围绕钛白粉、海绵钛、钛材、钒制品等终端产品，定向招引深加工与应用的龙头企业，提升就地转化率和附加值。
2. **增量培育**：设立转型专项，扶持新能源、电子信息、机械制造等非资源型产业，降低对单一资源型产业的依赖。
3. **数据补基**：尽快补充2024年全年GDP、规上工业总产值、钒钛深加工产品产量占比、园区集聚度等关键指标，为精准校准转型进度和考核提供依据。

## 一、产业现状分析

# 攀枝花市产业现状与2024年主要经济指标分析

> 说明：本次采集材料以2025年前三季度经济运行数据及“十四五”工业发展规划为主，**2024年全年主要经济指标在原始材料中未直接提供**，相关数据缺失处已明确标注。以下分析以可获取的最新数据（2025年前三季度）为基准，并结合规划文件交叉印证产业结构特征。


## 1. 产业概况

### 1.1 产业规模

攀枝花市经济总量在2025年前三季度达到 **1058.57亿元**，按不变价格计算同比增长4.5%（材料[1]）。三次产业结构为 **第一产业70.12亿元、第二产业585.14亿元、第三产业403.31亿元**，二产占比约55.3%，工业主导型经济特征显著（材料[1]）。

工业方面，2025年前三季度规上工业增加值同比增长4.5%，34个行业大类中18个行业实现增长，增长面52.9%（材料[1]）。从历史基数看，“十三五”末（2020年）全市规上工业企业349户，资产总额2706.5亿元，全年营业收入1922.3亿元，工业对经济增长贡献率达69.8%（材料[2]）。“十四五”规划目标为规上工业总产值达到2600亿元左右、规上工业增加值年均增速7.5%（材料[2]）。

**2024年全年产值、产量、从业人数等细分数据：数据缺失**（原始材料未提供）。

### 1.2 在经济中的地位

攀枝花是典型的资源型工业城市，工业是经济绝对主体。2020年工业贡献率69.8%（材料[2]），2025年前三季度二产占比仍超五成（材料[1]）。农业体量较小但特色鲜明，前三季度农林牧渔业总产值144.99亿元，蔬菜及食用菌98.32万吨、水果66.99万吨（材料[1]），契合其“康养+特色农业”定位。第三产业增速6.0%，与全省持平，消费品市场平稳（社零289.46亿元，增长5.7%）（材料[1]）。

### 1.3 发展历程关键节点

- **“十三五”期间**：规上工业增加值年均增长6.3%，钒钛占工业比重由5.3%提升至17.2%，国产EB炉、高炉渣提钛、氯化钛渣等产业化项目落地，电子信息产业和氯化钛白实现“零”的突破（材料[2]）。
- **2021—2025年（“十四五”）**：明确“1+3+3”现代工业体系，提出建成世界级钒钛产业基地，目标钛白粉100万吨、海绵钛及钛锭10万吨、钛材1万吨、钒制品6万吨产能（材料[2]）。
- **2025年**：市委提出“两试引领、五市并进、共富共美”工作体系，统筹“三场战役”，经济运行稳中提质（材料[1]）。


## 2. 产业链结构

### 2.1 上游（原材料/资源/装备）

攀枝花核心上游是 **钒钛磁铁矿采选业**，这是整个工业体系的“底盘”。规划明确以提高回采率、回收率、综合利用率为主线，推进红格南矿区开发，并加大钒、钛、钴、镍、钪、镓等伴生矿低成本绿色分离提纯技术攻关（材料[2]）。2025年前三季度，有色金属矿采选业增加值同比增长8.5%（材料[1]），上游资源端保持扩张。装备方面，国产EB炉等高端冶金装备已实现产业化应用（材料[2]）。

### 2.2 中游（生产/加工）

中游以 **钢铁、钒钛、石墨3大先进材料产业** 为主导，机械制造、新能源、绿色化工及建材3大优势产业为支撑（“1+3+3”体系，材料[2]）。2025年前三季度，化学原料和化学制品制造业增长8.6%，电力、热力生产和供应业增长11.5%（材料[1]），显示钒钛化工与能源加工环节增势较好。但规上工业增加值增速（4.5%）低于全国（6.2%）、全省（7.1%）1.7和2.6个百分点（材料[1]），反映中游加工深度与附加值仍有提升空间。

### 2.3 下游（销售/出口/应用）

下游覆盖钛白粉、海绵钛、钛材、钒制品等终端材料，应用于航空航天、化工、新能源储能等领域。规划目标产能显示其下游产品体系已具规模野心（材料[2]）。消费品端，家电音像器材类零售额增长87.5%、家具类增长44.1%（材料[1]），内需拉动明显。**出口数据：数据缺失**。

### 2.4 本县在产业链中的位置

**强项**：上游资源采选与中游钒钛初级加工，资源禀赋全国独有，标委会落户、省级制造业创新中心创建（材料[2]）。
**弱项**：规划文件自述“工业仍处在产业链前端，产业结构和企业结构单一，资源就地加工转化率不高，中小企业集群支撑不足，新兴产业发展缓慢”（材料[2]），即深加工与终端应用环节薄弱。


## 3. 市场主体

### 3.1 龙头企业

原始材料未列具体企业名称，但提及“国产EB炉、高炉渣提钛、50万吨钛精矿升级转化氯化钛渣”等项目实施主体，以及“睿恩光电”等延链补链项目（材料[2]）。**龙头企业具体名称、规模数据：数据缺失**，建议补充攀钢集团等核心企业2024年经营数据。

### 3.2 中小企业与合作社

2020年末规上工业企业349户（材料[2]）。“十四五”规划提出“培育壮大中小企业集群”（材料[2]），但**当前中小企业、合作社具体数量：数据缺失**。

### 3.3 产业集群/园区

规划提出“优化产业空间布局、推动集聚集群发展、提升园区承载能力”，并构建“市域内圈—金沙江区域中圈—成渝贵昆外圈”三个圈层协同格局（材料[2]）。**园区具体名称、入驻企业数、产值：数据缺失**。


## 4. 发展阶段判断

### 判断：**成熟期向转型期过渡阶段**

**依据：**

1. **成熟期特征明显**：工业体系完整、资源型主导产业（钒钛钢铁）体量大、贡献率高（工业贡献率69.8%），规上企业近350户，产业链上游和中游基础雄厚（材料[2]）。
2. **转型期信号突出**：一是增速承压，2025年前三季度GDP增速4.5%低于全国、全省（材料[1]）；二是结构单一问题被官方明确承认，“产业链前端、转化率不高、新兴产业缓慢”（材料[2]）；三是主动转型动作密集——“十四五”规划推动“钢铁城市向新材料工业城市和机械制造业城市转型”、“攀枝花制造向攀枝花智造提升”（材料[2]），并布局新能源、电子信息等增量产业。
3. **转型成效初显但未完成**：钒钛占比从5.3%升至17.2%、氯化钛白等深加工实现突破（材料[2]），但二产增速（3.6%）仍低于整体，说明新旧动能转换尚未完成（材料[1]）。

**结论**：攀枝花产业处于“资源型成熟产业支撑 + 新旧动能转换攻坚”的转型期，核心任务是延长钒钛产业链、提升就地转化率、培育非资源型增量产业。建议重点关注2024年全年规上工业总产值、钒钛深加工产品产量占比、园区集聚度等指标以精确校准转型进度（上述2024年数据当前缺失，需补充采集）。


**数据缺口提示**：2024年全年GDP/规上工业总产值、从业人数、出口额、龙头企业明细、园区经济数据均未在原始材料中提供，建议通过攀枝花市2024年统计公报及统计年鉴补充。
