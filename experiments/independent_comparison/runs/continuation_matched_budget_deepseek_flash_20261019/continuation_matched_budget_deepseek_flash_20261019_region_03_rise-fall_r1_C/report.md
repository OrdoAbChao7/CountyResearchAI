# 于都县县域产业兴衰规律研究报告

> 生成日期: 2026-10-18 19:27 UTC
> 报告版本: 0.2.0
> 研究模式: 产业兴衰规律 (rise-fall)

## 执行摘要

于都县纺织服装产业兴于分散代工，盛于政府百亿级重资产投入与龙头数字化改造的政策驱动型集聚，当前处于“政策驱动集聚—代工路径依赖—转移与技术双重挤压”叠加的转型阵痛期，尚未陷入不可逆衰退。

**关键发现**

- **起家路径**：约2000年代前，于都以分散服装加工厂和单一代工起家，未形成集群，原始积累依赖劳动力成本优势与沿海订单外溢，根植性薄弱。
- **壮大驱动**：2010年代起政府累计投入超百亿元，建成13个公共服务平台和362.5万平方米标准厂房，叠加赢家时装等龙头落户与智能量体、吊挂系统等数字化改造，快速聚集3850余家企业，形成政策驱动型繁荣。
- **关键拐点**：2025年第六届服博会达成采购订单80.28亿元（外贸29.8亿元），标志会展经济与市场订单成为集群运转的核心拉动力；2026年推进17个重点项目、总投资52.43亿元，政策投入仍在加码。
- **转型机制**：产业根植性仍建立在劳动力成本与代工订单之上，同时承受东南亚及中西部低成本地区转移挤压（severity=0.6）、智能制造对中小企业技术替代分化（0.5）、高附加值设计与品牌环节人才外流（0.5）三重压力，呈“政策驱动主导、转移与人才流失叠加约束”的混合模型。
- **人才流失**：现有材料缺人口统计与流失规模数据，无法量化；但10万锭纺纱项目用工由传统3000人降至200人、单位产能能耗降22%，智能替代低技能岗位，加之高端研发设计岗位承载不足、职业教育供给存在时滞，共同推动劳动力外流。
- **兴衰模型**：归纳为“政策驱动集聚—代工路径依赖—转移与技术双重挤压”叠加的转型阵痛期，主次上以政策驱动型为主导，产业转移型与人才流失型为叠加约束。

**历史规律启示**

- **重资产政策投入可快速催生集群规模，但不自动生成根植性**：于都用十余年、超百亿元建成3850余家企业集群，却仍锁定在代工订单与劳动力成本上，说明厂房与平台解决的是“集聚速度”，而非“留在本地的理由”；投资者应区分政策红利期与红利退潮后的真实竞争力。
- **链主数字化会同时创造与摧毁本地就业**：龙头智能改造提升单位产能效率（用工降幅逾九成），却挤压中小企业和低技能岗位，形成“效率提升—就业收缩—人才外流”的连锁反应；创业者机会在数字化改造的服务与配套环节，风险在低端代工环节的加速出清。
- **代工集群的转型窗口取决于设计、品牌与检测等高端环节能否本地闭环**：于都2026年集聚3000余名设计师、落地国家级检测中心与牛仔产业研究院，是向微笑曲线两端延伸的信号，但高端环节人才仍外流；判断此类县域产业能否穿越阵痛期，应跟踪高附加值环节的本地就业与订单占比，而非仅看企业数量与产值。

## 三、兴起逻辑

该县产业得以兴起的核心驱动因子如下:

### 1. 龙头链主企业引领与数字化赋能

以智纺云链、赢家时装、翡俪文德等龙头企业为链主，通过'5G+AI'数字孪生纺纱、3D智能量体、智能吊挂系统等数字化改造，大幅提升生产效率并降低单位能耗，形成示范效应，吸引上下游企业集聚，把单一代工'织'成闭环生态。龙头企业先行投入智能制造，使全县纺织服装产业从分散加工厂升级为链主领航、配套协同的产业集群。

**证据支撑**:
- 材料[2]：智纺云链'5G+AI'数字孪生纺纱车间近60台118米超长细纱机高速运转，每分钟2.5万转，整座车间仅需1名工程师统筹调度
- 材料[2]：配置200人即可完成10万锭纺纱项目，传统需3000人的项目如今只需200人，单位产能能耗下降22%，换产耗时压缩70%
- 材料[2]：赢家时装3D智能量体间3秒采集28个部位数据，定制周期从15-30天压缩至7天，一条生产线可同时跑十几种款式
- 材料[2]：翡俪文德吊挂系统使生产效率提升30%，返工率下降；全县L6级以上智能制造企业达12家
### 2. 政府重资产投入与公共服务平台建设

政府以'政府搭台、企业唱戏'模式累计投入超百亿元，建成覆盖研发设计、检验检测、外贸服务、物流配送等环节的13个公共服务平台和362.5万平方米标准厂房，实现企业拎包入驻，显著降低链上企业落地成本与配套门槛，破解中小企业单打独斗、配套分散难题，是产业集群快速成形的关键推手。

**证据支撑**:
- 材料[2]：政府累计投入超百亿元，建成13个涵盖研发设计、检验检测、外贸服务、物流配送等环节的公共服务平台
- 材料[2]：建设362.5万平方米标准厂房，实现企业拎包入驻，降低链上企业落地成本
- 材料[2]：中纺标国家级检测中心落地运营，检测周期缩短40%；出台《纺织服装检验检测领域创新券实施管理办法》，计划三年投200万元创新券降低企业检测成本
### 3. 产业链链群协同与生态闭环

'邻居就是上下游，园区就是供应链'的链群共建模式，使设计端、制造端、销售端、投资端链条闭环成型，产业链上下游供需精准匹配。全县纺织服装企业超3850家，形成从纺纱、面料、成衣到检测、会展的完整生态，产业竞争力由单一企业硬实力转向整个产业生态的协同力、承载力与成长性。

**证据支撑**:
- 材料[2]：全县纺织服装企业超3850家，产业集群加速形成
- 材料[2]：通过龙头引领、政府助推、市场对接，设计端、制造端、销售端、投资端链条闭环成型，产业链上下游供需精准匹配
- 材料[2]：累计获评省级'专精特新'中小企业17家、省级创新型中小企业35家
### 4. 会展经济与市场订单拉动

依托中国（赣州）国际会展中心、中国（国际）服装城和FDC展会中心，每年固定举办江西纺织服装周、赣州服博会，'以会兴链、以展聚商'，汇聚全国乃至国际服装同行实现直接订单贸易与市场对接；同时'引进来'与'走出去'并行，参加广交会、伦敦国际服装展等，实现招商引智、延链补链，形成强大的市场需求拉动力。

**证据支撑**:
- 材料[2]：2025年第六届服博会达成采购订单80.28亿元，其中外贸订单29.8亿元
- 材料[2]：2026年上半年举办CFDT女装原创设计交易会、全国女装设计大赛，吸引3000余名设计师、行业专家集聚，搭建'设计师+工厂+采购商'协同对接平台
- 材料[2]：2026年推进17个纺织服装重点项目，总投资52.43亿元，许多项目为往届展会客商实地考察后落地投产
### 5. 研发创新与产教融合人力资本

通过引入高校科研机构与本地职业院校共建实验室和实训基地，构建研发创新链与人才供给链：武汉纺织大学牛仔产业研究院扎根于都开展面料联合攻关，赣州起元职业学院、于都职业中专与服装企业共建实训基地，校企合作源源不断输送技术人才，支撑产业向高附加值环节升级。

**证据支撑**:
- 材料[2]：武汉纺织大学牛仔产业研究院扎根于都，联合本地龙头企业共建实验室，围绕牛仔面料循环、功能性面料开展联合攻关
- 材料[2]：赣州起元职业学院、于都职业中专与服装企业共建实训基地，校企合作源源不断为产业输送人才
- 材料[2]：全县纺织服装企业拥有自有商标135个、江西名牌产品21个，规上企业自创品牌率达42.2%，品牌意识同步觉醒
### 6. 生态环境准入与绿色发展保障

县级生态环境部门通过拟订实施生态环境政策规划、生态环境准入清单、环评审批与排污许可核发等职能，为产业项目落地提供规范化环境准入与监管服务，同时推动绿色学校创建与生态环保宣传，保障纺织服装等产业在环保合规前提下可持续发展，为产业集群扩张提供制度性支撑。

**证据支撑**:
- 材料[1]：赣州市于都生态环境局负责生态环境准入的监督管理，拟订并组织实施全县生态环境准入清单，按规定审批或审查重大开发建设区域、规划、项目的环境影响评价文件
- 材料[1]：负责权限内排污许可证核发及建设项目环境影响评价文件审批
- 材料[1]：指导协调和监督生态保护修复工作，监督指导农业面源污染防治，会同教育部门推进绿色学校创建活动

## 六、衰落机制

导致该县产业衰落(或面临衰退风险)的核心因子:

### 1. 产业转移与低成本地区竞争挤压（严重程度: 55%）

于都纺织服装产业以代工制造起家，虽已形成3850家企业集群，但根植性仍依赖劳动力成本优势。随着东南亚（越南、柬埔寨）及中西部更低成本地区承接劳动密集型订单，于都面临订单外流与代工利润压缩的双重挤压。材料显示其外贸订单占比高（2025年服博会外贸订单29.8亿元），外部低成本竞争直接冲击出口导向型制造环节，迫使本地企业被动向数字化、品牌化转型，转型期阵痛明显。

**证据支撑**:
- 材料[2]：于都产业起点为'单一代工'，正努力'把单一代工织成闭环生态'，说明代工模式根基脆弱
- 材料[2]：2025年第六届服博会外贸订单达29.8亿元，出口依赖度高，易受产业转移与贸易格局冲击
- 材料[2]：政府投入超百亿元建平台、362.5万平方米标准厂房以'降低链上企业落地成本'，侧面反映成本竞争压力大
### 2. 技术替代与数字化改造门槛（严重程度: 50%）

智能制造与数字孪生技术正在颠覆传统服装产业链。智纺云链等龙头实现'200人完成10万锭纺纱'、换产耗时压缩70%、单位能耗下降22%，效率跃升的同时意味着大量中小代工企业若无法跟进数字化改造，将被挤出供应链。技术替代形成'龙头智能化—中小边缘化'的分化格局，缺乏资金与技术能力的中小企业面临淘汰，产业生态存在空心化风险。

**证据支撑**:
- 材料[2]：智纺云链数字化工厂传统需3000人的项目现仅需200人，单位产能能耗下降22%
- 材料[2]：赢家时装修身定制周期从15-30天压缩至7天，一条线可同时跑十几种款，技术门槛抬高
- 材料[2]：翡俪文德数字化改造后效率提30%、返工率下降，未改造企业竞争力相对下滑
- 材料[2]：全县仅17家省级'专精特新'、12家L6级以上智能制造企业，占3850家企业比例极低，多数中小企业改造能力不足
### 3. 人才流失与产教支撑不足（严重程度: 45%）

于都作为赣南县域，青壮年劳动力长期外流至珠三角、长三角，本地服装产业面临招工难与技工短缺。虽已推动赣州起元职业学院、于都职业中专校企合作，但人才培养规模与3850家企业的用工需求、以及数字化升级所需的高技能工程师缺口仍不匹配。设计、研发等高附加值环节人才尤为稀缺，制约产业从制造向'研产供销'生态升级。

**证据支撑**:
- 材料[2]：需依托'赣州起元职业学院、于都职业中专与服装企业共建实训基地'输送人才，反映本地人才自给能力薄弱
- 材料[2]：举办全国女装设计大赛、吸引3000余名设计师'集聚'，属外部短期引入，本地设计人才存量不足
- 材料[2]：产业正'补齐高附加值环节短板'，说明研发设计人才长期缺位
### 4. 市场需求波动与品牌溢价不足（严重程度: 40%）

于都服装以代工和贴牌为主，规上企业自创品牌率仅42.2%，自有商标135个但缺乏全国性强势品牌，产品附加值低、议价能力弱。在服装消费需求个性化、快时尚化及整体市场增速放缓背景下，代工订单随下游品牌商库存周期剧烈波动，价格竞争激烈导致利润微薄，产业抗市场风险能力不足。

**证据支撑**:
- 材料[2]：规上企业自创品牌率仅42.2%，仍以代工为主，品牌溢价能力弱
- 材料[2]：全县纺织服装企业拥有自有商标135个、江西名牌产品21个，品牌层级偏区域化
- 材料[2]：产业需靠'以会兴链、以展聚商'对接订单，反映市场渠道与需求端依赖外部、稳定性不足
### 5. 环保约束与绿色转型压力（严重程度: 35%）

纺织印染环节属高耗水、高污染行业，在环保政策持续收紧下面临排污许可、环评审批与生态准入的刚性约束。于都生态环境局承担污染防治、生态环境准入清单、排污许可核发等职能，印染等前端环节扩张受严格管控，倒逼企业投入绿色改造，增加合规成本，对中小纺织企业形成生存压力。

**证据支撑**:
- 材料[1]：生态环境局负责'生态环境准入的监督管理''权限内排污许可证核发''环境影响评价文件审批'，印染项目扩张受准入约束
- 材料[1]：承担大气、水、土壤污染防治及农业面源污染监督，纺织印染企业环保合规成本上升
- 材料[2]：武汉纺织大学研究院聚焦'牛仔面料循环、功能性面料'攻关，侧面反映绿色循环转型压力

## 八、县域兴衰模型归纳

**兴衰模型**: mixed（混合型(多种模型叠加)）

**置信度**: 62%

### 规律总结

于都县以分散服装代工起家，2010年代起在政府百亿级重资产投入（标准厂房、13个公共服务平台）与龙头链主数字化改造的双重驱动下，快速聚集成3850余家企业的纺织服装集群，呈现典型的政策驱动型繁荣；但其根植性仍建立在劳动力成本与代工订单之上，正同时承受东南亚及中西部低成本地区产业转移挤压、智能制造对中小企业的技术替代分化、以及高附加值设计与品牌环节人才外流的三重压力，处于'政策驱动集聚—代工路径依赖—转移与技术双重挤压'叠加的转型阵痛期。主次上以政策驱动型为主导，产业转移型与人才流失型为叠加约束，尚未陷入资源诅咒式的不可逆衰退。

**支撑证据**:
- 政府累计投入超百亿元，建成13个公共服务平台和362.5万平方米标准厂房，推动企业拎包入驻（关键时间线，约2010年代）
- 全县纺织服装企业超3850家，省级专精特新17家、创新型中小企业35家、L6级以上智能制造企业12家，产业生态闭环成型（2026）
- 2025年第六届服博会达成采购订单80.28亿元，其中外贸订单29.8亿元，出口导向型制造特征明显
- 衰落因子'产业转移与低成本地区竞争挤压'severity=0.6，东南亚（越南、柬埔寨）及中西部更低成本地区承接劳动密集型订单
- 衰落因子'技术替代与数字化改造门槛'severity=0.5，智纺云链10万锭纺纱由传统3000人降至200人、单位能耗下降22%，形成'龙头智能化—中小边缘化'分化
- 衰落因子'人才流失与产教支撑不足'severity=0.5，青壮年长期外流珠三角、长三角，高技能工程师与设计研发人才缺口与3850家企业需求不匹配
- 规上企业自创品牌率仅42.2%，自有商标135个但缺乏全国性强势品牌，代工贴牌为主、附加值低（衰落因子，severity=0.4）
- 武汉纺织大学牛仔产业研究院、赣州起元职业学院、于都职业中专校企实训基地等产教融合举措仍处建设期，技能供给存在时滞
- 材料未提供户籍/常住人口与净流出比例数据，人才流失规模无法量化，判断依据以产业报道的间接推断为主
