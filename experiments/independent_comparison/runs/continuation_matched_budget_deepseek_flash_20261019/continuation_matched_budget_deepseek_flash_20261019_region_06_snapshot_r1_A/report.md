# 临泽县产业现状与2024年主要经济指标研究报告（snapshot）

**研究说明**：本报告为传统网页检索的snapshot模式成果，仅依据所给5条资料撰写。报告严格区分**事实**（资料明确记载）、**推断**（基于事实的合理分析）与**资料缺口**（现有资料无法回答的问题），所有关键事实均标注来源编号，不编造任何无资料支持的数字。


## 一、2024年主要经济指标（核心事实）

据临泽县统计局发布的《临泽县2024年主要经济指标完成情况》[1]，2024年临泽县主要指标如下：

| 指标 | 2024年数值 | 同比增速 |
|---|---|---|
| 地区生产总值 | 79.68亿元 | +6.1% |
| 第一产业增加值 | 26.35亿元 | +7.7% |
| 第二产业增加值 | 15.26亿元 | +10.8% |
| 第三产业增加值 | 38.07亿元 | +3.3% |
| 固定资产投资额 | —（仅给增速） | -4.8% |
| 工业增加值 | —（仅给增速） | +10.5% |
| 建筑业增加值 | —（仅给增速） | +11.3% |
| 社会消费品零售总额 | —（仅给增速） | +6.4% |
| 一般公共预算收入 | 3.01亿元 | +6.9% |
| 一般公共预算支出 | 24.89亿元 | +17.1% |
| 城镇居民人均可支配收入 | 35435元 | +5.6% |
| 农村居民人均可支配收入 | 23582元 | +7.8% |

**事实**：以上数据均直接来自资料[1]（临泽县统计局，2025-04-15发布）。

**推断**：从三次产业增速看，二产（+10.8%）>一产（+7.7%）>三产（+3.3%），二产是2024年增长最快的部门；但三产增加值绝对额（38.07亿元）仍居三次产业之首。固定资产投资负增长（-4.8%）与GDP正增长并存，说明当年经济增长主要靠存量产出而非新增投资拉动。一般公共预算支出增速（+17.1%）显著高于收入增速（+6.9%），财政支出扩张明显。

**资料缺口**：
- 资料[1]未给出固定资产投资、工业增加值、建筑业增加值、社零总额的**绝对额**，仅有增速；
- 未给出2024年三次产业结构比的官方表述（资料[2]仅给出"上年"即2024年的结构比35.1:18.4:46.5，可据此推算，但属间接数据）；
- 未给出2024年常住人口、人均GDP等指标（资料[2]的2025年公报含人均GDP 79714元，但那是2025年数据）。


## 二、产业结构与产业现状

### 2.1 三次产业结构

**事实**：资料[2]（临泽县2025年统计公报）载明，2025年三次产业结构比为34.6:18.6:46.8，"与上年相比"第一产业下降0.5个百分点、第二产业上升0.2个百分点、第三产业上升0.3个百分点；并明确"由上年的35.1:18.4:46.5调整"而来。据此，**2024年三次产业结构比为35.1:18.4:46.5**（该数值为资料[2]转述的官方口径）。

**推断**：临泽县经济结构呈"三产为主、一产次之、二产偏轻"的格局。一产占比超过三分之一，说明农业在县域经济中地位突出；二产占比不足两成，工业化程度相对有限；三产占比近半，但2024年三产增速仅3.3%，是三次产业中最慢的。

### 2.2 农业与玉米制种产业

**事实**：
- 资料[3]载明，临泽县"玉米制种面积持续稳定在30万亩以上，年产优质种子约1.5亿公斤"，并描述"企业＋基地＋农户"模式带动全程机械化与标准化生产。
- 资料[2]载明，2025年农作物总播种面积54.59万亩（+1.82%），粮食作物播种面积37.83万亩（+0.48%），其中玉米面积35.7万亩，玉米面积中制种面积30.61万亩，较上年减少1.21万亩。

**推断**：玉米制种是临泽农业的核心支柱。以2025年数据看，制种面积占玉米面积约85.7%、占粮食作物面积约80.9%、占总播种面积约56.1%（均为据资料[2]数据的计算值）。资料[3]称制种面积"持续稳定在30万亩以上"，与资料[2]的30.61万亩相互印证。2025年制种面积比上年减少1.21万亩，说明该产业规模存在小幅波动，但总体仍处高位。

**资料缺口**：
- 资料未给出2024年制种面积、制种产量、制种产值的精确数值（资料[3]为"十四五"综述性表述，资料[2]为2025年数据）；
- 未给出制种产业对一产增加值或农民收入的贡献率；
- 未给出除玉米制种外其他农业产业（如蔬菜、畜牧、林果）的规模数据。

### 2.3 工业与新型工业化

**事实**：
- 资料[4]载明，临泽县坚持"一手抓传统产业改造升级，一手抓新兴产业培育壮大"，传统产业涉及农特产品加工、冶金建材、矿产等；新兴产业方面，易事特（张掖）储能技术有限公司已建成储能装备制造自动化生产线，完成24个储能集装箱约160兆瓦订单。
- 资料[4]载明，临泽县宏鑫矿产实业有限公司依托锰铁矿资源开展开采、精选、矿产品销售，2024年获评甘肃省民营经济50强和富锰渣3大优势企业之一；该公司投资2.5亿元新建2座216立方米富集炉，称"5月份投产使用，投产后将实现产能30万吨，产值20亿元"。
- 资料[1]载明，2024年工业增加值同比增长10.5%，建筑业增加值同比增长11.3%。

**推断**：临泽工业呈"传统矿产冶金＋新兴储能装备"双线并进格局。宏鑫矿产的技改扩产（2.5亿元投资、宣称产值20亿元）若如期达产，对县域工业产值将有显著拉动；但该"产值20亿元"为企业方预期口径，且资料[4]发布于2025年5月、称"5月份投产使用"，其实际达产情况在现有资料中无法核实。易事特储能项目显示临泽已切入新能源储能装备赛道，但资料未给出该企业的产值、税收等贡献数据。

**资料缺口**：
- 资料[1]仅有工业增加值增速（+10.5%），无工业增加值绝对额、规上工业企业家数、工业税收等；
- 宏鑫、易事特等企业的实际产值/营收数据缺失，资料[4]中的"产值20亿元"为企业预期，不可作为已实现事实引用；
- 未给出工业内部行业结构（矿产冶金、农副产品加工、储能装备等各自占比）。

### 2.4 固定资产投资与项目建设

**事实**：资料[1]载明2024年固定资产投资额同比下降4.8%。资料[3]提及"项目建设加快推进"，但为综述性表述，未给具体投资额。

**推断**：在宏鑫2.5亿元技改、易事特储能产线等工业项目推进的背景下，全县固定资产投资仍录得负增长，说明投资下滑可能主要来自其他领域（如基础设施、房地产），或项目投资尚未形成当年统计入库量。此为推断，资料未给出投资分项数据。

**资料缺口**：固定资产投资绝对额、分产业/分领域投资结构、重点项目清单及年度完成投资额均缺失。

### 2.5 消费、财政与居民收入

**事实**：2024年社零总额同比+6.4%；一般公共预算收入3.01亿元（+6.9%）、支出24.89亿元（+17.1%）；城镇、农村居民人均可支配收入分别为35435元（+5.6%）、23582元（+7.8%）[1]。

**推断**：农村居民收入增速（+7.8%）高于城镇居民（+5.6%），城乡收入比约为1.50:1（35435/23582，计算值），城乡差距相对较小。财政支出增速远高于收入增速，收支缺口需依靠上级转移支付等弥补（此为推断，资料未载明转移支付数据）。

**资料缺口**：社零总额绝对额、财政收入分项（税收/非税）、转移支付规模、城乡居民收入构成等均缺失。
