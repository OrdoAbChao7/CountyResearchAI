# 于都县产业现状与2024年主要经济指标：基于现有资料的Snapshot研究报告

**研究模式：snapshot（快照）｜研究对象：江西省赣州市于都县｜资料截止：以所给资料为准**


## 一、研究说明与方法边界

本报告严格依据所给5份资料撰写，采用"事实—推断—资料缺口"三分法逐条标注。需特别说明三点方法边界：

1. **资料[1]为残篇**：于都县2024年统计公报页面仅呈现农业两张表、工业与建筑业开头段落，GDP总量、财政、投资、消费、居民收入等核心指标在资料中缺失，无法据以填报。
2. **资料[2]为2025年公报**：其GDP、财政、农业等数据属2025年，不能充当2024年指标；但其中"三次产业结构由去年同期的10.6:32.4:57.0调整"一句，反向提供了2024年于都县三次产业结构数据，可作为2024年事实使用（属资料内可验证的间接事实）。
3. **资料[3][5]分别为全国宏观与长沙低空经济资料，与于都县无直接对应关系**；资料[4]为赣州市级纺织服装规划，仅可用于判断于都县所处区域产业政策环境，不能直接等同于于都县产业数据。


## 二、2024年主要经济指标：可得事实与缺口

### 2.1 可确认的2024年事实

**事实F1：2024年于都县三次产业结构为10.6:32.4:57.0。**
来源：资料[2]（于都县2025年统计公报）载"三次产业比例结构由去年同期的10.6:32.4:57.0调整为10:32.4:57.6"。此处"去年同期"即2024年。该数据为第二手转述，非2024年公报原文，置信度中等。

**事实F2：2024年于都县工业增加值947850万元（约94.79亿元），较上年增长9.7%，占GDP比重26.9%，较上年提升0.9个百分点；规模以上工业增加值增长13.8%。**
来源：资料[1]（2024年统计公报）"三、工业和建筑业"首段。

**事实F3：2024年于都县规模以上工业总产值2090798万元（约209.08亿元），比上年增长11.7%；销售产值2051235万元（约205.12亿元），增长11.8%；工业产销率98.1%；规模以上工业营业收入207.03亿元。**
来源：资料[1]同段。注：营业收入句在资料中戛然而止，未见增长率。

**事实F4：2024年于都县粮食总产量242403吨，增长5.2%；蔬菜349941吨，增长6.0%；脐橙107244吨，与上年持平；肉类总产量94833吨，下降0.3%；生猪存栏258678头，增长11.5%。**
来源：资料[1]表1、表2。

**事实F5（推断性事实，需谨慎）：由F2可反推2024年于都县GDP约352.4亿元。**
计算：947850万元 ÷ 26.9% ≈ 352.4亿元。**此为本报告推断，非资料直接给出**；且因工业增加值占比系四舍五入值，反推结果存在误差。资料[2]显示2025年GDP为3760419万元（376.04亿元），2025年二产增加值1217558万元、占比32.4%，与2024年结构数据可相互校验，但2024年GDP确切值在资料中缺失。

### 2.2 资料缺口（2024年）

以下2024年于都县指标在所给资料中**完全缺失**，本报告不填列、不推测：

- GDP总量及增速、人均GDP；
- 第一、三产业增加值绝对额；
- 财政总收入、一般公共预算收入、税收收入；
- 固定资产投资、社会消费品零售总额、进出口；
- 城乡居民人均可支配收入；
- 规上工业企业数量、利润总额；
- 纺织服装等主导产业的分行业产值/企业数。

**资料缺口说明**：资料[1]页面在"规模以上工业营业收入达207.03亿元，"处截断，其后建筑业、固定资产投资、国内贸易、对外经济、财政金融、居民收入等章节均未呈现。因此本报告无法完成"2024年主要经济指标"的完整 snapshot，仅能就工业与农业部分作答。


## 三、产业现状：可支撑的判断

### 3.1 工业：主导地位上升，但行业结构不明

**事实**：2024年工业增加值占GDP 26.9%，比上年提升0.9个百分点；规上工业增加值增速13.8%，高于工业整体增速9.7%（资料[1]）。**推断**：规上工业是拉动于都2024年工业增长的主要力量，工业在县域经济中的分量上升。**缺口**：资料未列出于都县规上工业的行业构成，无法判断纺织服装、电子信息等具体产业的贡献。

### 3.2 农业：粮食与蔬菜扩张，脐橙持平，畜牧分化

**事实**：见表1、表2数据（F4）。**推断**：2024年于都农业呈现"种植业稳增、畜牧业微降"格局；生猪存栏增长11.5%而肉类总产量下降0.3%，可能反映出栏节奏或存栏结构变化，但资料不足以解释原因。**缺口**：农林牧渔业总产值、农业增加值等2024年数据缺失（资料[2]仅有2025年数据615153万元，不可移用）。

### 3.3 区域产业政策环境：纺织服装是赣州市级重点方向

**事实**：赣州市政府办公室于2024年5月10日印发《赣州市纺织服装产业发展规划纲要（2024—2035年）》，由中国纺织工业联合会、中国服装协会等机构人员参与编制；规划第三章分析赣州纺织服装产业"产业规模良性增长、产业集聚初见成效、产品门类丰富多元"等优势，同时指出"产业缺乏协同规划、整体发展层级较低、强链补链尚需推进"等问题（资料[4]）。
**推断**：于都县作为赣州市下辖县，处于该市级纺织服装产业规划覆盖范围内，纺织服装可能是其产业政策重点方向之一。**重要限定**：资料[4]为石城县信息公开页面转载的市级文件，**未提及于都县的具体产业规模、企业数量或园区情况**；资料[1]亦未列纺织服装行业数据。因此"纺织服装是于都县主导产业"这一常见说法，在本资料集内**仅有市级政策环境支撑，缺乏于都县级数据支撑**，应列为待验证推断。

### 3.4 与全国背景的对照（仅作背景，不作于都结论）

**事实**：2024年全国GDP 134.9万亿元、增长5%；规上制造业增加值增长6.1%，高技术制造业增长8.9%；服务业增加值占GDP约56.7%（资料[3]）。**推断**：于都2024年规上工业增加值13.8%的增速高于全国规上制造业6.1%的增速，但二者口径（规上工业 vs 规上制造业）不同，不宜直接比较，仅可作为"于都工业增速相对较快"的弱旁证。资料[5]为长沙低空经济，与于都县无关联，本报告不采用。


## 四、结论（Snapshot）

1. **可确认**：2024年于都县工业增加值94.79亿元、增长9.7%、占GDP 26.9%；规上工业总产值209.08亿元、增长11.7%；三次产业结构10.6:32.4:57.0；农业主要产品产量见F4。以上均有资料[1][2]对应。
2. **可推断**：2024年GDP约352亿元（反推，非原文）；工业占比上升、规上工业领跑；农业稳中分化；纺织服装处于赣州市级规划覆盖下但于都县级数据缺失。
3. **主要缺口**：2024年GDP、财政、投资、消费、收入、行业结构等核心指标因资料[1]截断而缺失，本 snapshot **不构成完整的年度经济指标画像**。若要补齐，需获取于都县2024年统计公报全文或于都县统计局原始发布件。
4. **资料使用警示**：资料[2]为2025年数据，除"去年同期"结构句外不得移用为2024年事实；资料[3][5]与于都县无直接关系，仅[3]可作全国背景；资料[4]为市级规划，不能替代于都县级产业数据。
