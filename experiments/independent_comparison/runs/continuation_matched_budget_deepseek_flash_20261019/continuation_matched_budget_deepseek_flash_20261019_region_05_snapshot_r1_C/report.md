# 白山市 白山市产业现状与2024年主要经济指标产业研究报告

> 生成日期: 2026-10-18 19:42 UTC  
> 报告版本: 0.1.0

## 执行摘要

白山市产业正处于资源型经济向特色轻工与医药健康转型的关键期，三产主导、二产偏弱，新动能局部高增但投资与人口约束突出。

**关键发现**

- **产业规模与地位**：2025年全市GDP 590.17亿元、增长5.6%，三次产业结构12.8∶24.7∶62.5，第三产业占比超六成，第二产业仅占24.7%且建筑业下降3.7%，工业支撑力有限。

- **最突出优势**：特色轻工与医药制造增势强劲，规上制造业增长19.2%、酒饮制造增长33.6%，小型企业增长18.7%快于大中型企业，高新技术企业达46户，成长期亮点集中。

- **最关键瓶颈**：传统动能明显收缩，采矿业下降1.7%、固定资产投资下降10.2%、民间投资骤降37.4%；税收占地方级财政收入仅41.7%，产业创税能力偏弱。

- **结构性压力**：常住人口87.53万人、自然增长率-8.16‰，人口持续负增长；出口总额仅11.91亿元，经济外向度低，消费端汽车、药品、文化办公用品类同步下滑。

- **最紧迫行动**：补齐2024年分项数据、园区载体与龙头企业名录等基础材料，为精准招商与转型路径设计提供支撑。

**决策建议**

- **稳投资、稳预期**：针对民间投资骤降，梳理在建与拟建项目清单，重点保障医药、酒饮等成长期行业的要素供给与融资支持，遏制投资端失速。

- **强特色、补链条**：围绕医药制造、酒饮制造等增速领先环节，向下游品牌化、标准化延伸，同步修复采矿业与建筑业收缩带来的产业链前端缺口。

- **育主体、增税基**：以46户高新技术企业和154户规上工业为基础，培育中小科技型企业成长，逐步提升税收占财政收入比重，缓解人口负增长下的财政压力。

## 一、产业现状分析

# 白山市产业现状与主要经济指标分析

> **数据说明**：本次采集到的核心材料为《白山市2025年国民经济和社会发展统计公报》（材料[1]），其中2024年分项数据未单独披露。以下分析以2025年公报数据为主体，涉及"2024年主要经济指标"处，凡材料未覆盖的均标注"数据缺失"，不做推算编造。另需说明：白山市为地级市建制，本报告按"县域产业"分析框架对其市域产业进行解析。

---

## 1. 产业概况

### 1.1 产业规模

2025年白山市实现地区生产总值**590.17亿元**，比上年增长5.6%。三次产业增加值分别为：第一产业75.79亿元（增长4.9%）、第二产业145.58亿元（增长4.3%）、第三产业368.80亿元（增长6.2%）（材料[1]）。

从实物产量看：
- 粮食总产量32.05万吨（增长1.5%），其中谷物24.94万吨、豆类6.85万吨；
- 猪牛羊禽肉类总产量3.61万吨，猪肉1.91万吨、牛肉0.97万吨；
- 规模以上工业增加值增长11.4%，其中制造业增长19.2%、采矿业下降1.7%、电力燃气及水生产供应业增长6.5%（材料[1]）。

从业人数方面，公报未披露分产业从业人员数据，**数据缺失**；仅有人社口径的城镇新增就业9426人、失业人员再就业7159人等指标。

### 1.2 在经济中的地位

三次产业结构为**12.8∶24.7∶62.5**，呈现典型的"三产主导、二产偏弱"格局。第三产业占比62.5%，是经济主体；第二产业仅占24.7%，其中建筑业增加值41.55亿元且下降3.7%，说明工业支撑力有限。第一产业占比12.8%，但农林牧渔业增加值77.85亿元，与一产增加值75.79亿元基本吻合，农业以初级种养为主（材料[1]）。

财政贡献方面，全年地方级财政收入36.80亿元，增长53.2%，其中税收收入15.33亿元、增长7.1%——财政收入高增长主要非税拉动，税收占比仅41.7%，反映产业创税能力偏弱（材料[1]）。

### 1.3 发展历程

公报未提供产业发展沿革的系统数据，**关键节点数据缺失**。从现有指标可作有限判断：2021—2025年GDP增速、规上工业增加值增速、人均可支配收入等均以图表形式呈现（图1、图3、图6），但正文未列具体年份数值，无法还原完整历程。

## 2. 产业链结构

### 2.1 上游（原材料/种源/装备）

- **农业上游**：粮食种植面积69366.7公顷，其中谷物36501.7公顷、豆类32162.8公顷、薯类702.1公顷；生猪年末存栏14.48万头（下降7.1%）（材料[1]）。种源、饲料、农机装备等上游环节数据**缺失**。
- **工业上游**：采矿业增加值下降1.7%，有色金属矿采选业增长3.1%，表明矿产资源开采是工业原材料端的重要环节，但具体矿种、储量、开采量数据**缺失**（材料[1]）。

### 2.2 中游（生产/加工）

规上工业154户，轻重工业比例46.1∶53.9，轻工业增长19.3%、重工业增长5.1%。重点行业表现：医药制造业增长2.8%、酒饮料制造业增长33.6%、电力热力生产供应业增长5.9%、有色金属矿采选业增长3.1%（材料[1]）。可见中游加工以**医药、酒饮、电力、有色采选**为支柱，但各行业产值规模、企业数量分布**数据缺失**。

### 2.3 下游（销售/出口/应用）

- 社会消费品零售总额110.50亿元，增长4.9%；城镇97.94亿元、乡村12.56亿元（乡村增长11.2%，快于城镇）（材料[1]）。
- 进出口贸易总额11.91亿元，其中出口8.22亿元、进口3.69亿元，出口导向明显但总规模偏小（材料[1]）。
- 限上商品零售中，饮料类增长44.6%、通讯器材类增长30.6%、家电类增长22.5%，而汽车类下降3.8%、中西药品类下降8.6%、文化办公用品类下降32.8%（材料[1]）。

### 2.4 本县在产业链中的位置

**强项**：医药制造、酒饮制造等特色轻工加工环节增速较快（酒饮+33.6%），农业原料供给稳定（粮食+1.5%）。**弱项**：采矿业下滑（-1.7%）、建筑业下降（-3.7%）、固定资产投资下降10.2%（其中民间投资骤降37.4%），说明产业链的资本投入和前端开采环节收缩，下游出口规模仅11.91亿元，外向度低（材料[1]）。

## 3. 市场主体

### 3.1 龙头企业

公报未列具体企业名称，**龙头企业名单数据缺失**。可间接观察：规上工业154户，大中型企业增加值增长6.1%、小型企业增长18.7%，小型企业增速显著快于大中型，反映市场主体以中小规模为主（材料[1]）。

### 3.2 中小企业与合作社

中小企业、农民合作社数量**数据缺失**。仅知规上工业企业154户、国家高新技术企业46户（当年获批13户）、15个项目列入省级科技发展计划（材料[1]）。

### 3.3 产业集群/园区

公报未披露产业园区、集群的名称与产值，**数据缺失**。从行业结构推断，医药、酒饮、有色采选可能形成一定集聚，但缺乏园区载体数据支撑，不宜臆断。

## 4. 发展阶段判断

**判断：整体处于"转型期"，特色轻工处于"成长期"。**

依据：
1. **传统动能收缩**：采矿业下降1.7%、建筑业下降3.7%、固定资产投资下降10.2%、民间投资下降37.4%，传统资源型与投资驱动模式明显退潮（材料[1]）。
2. **新动能局部高增**：酒饮制造+33.6%、制造业整体+19.2%、小型企业+18.7%、高新技术企业达46户，轻工与科技型主体处于成长期（材料[1]）。
3. **需求端温和扩张但结构分化**：社零增长4.9%、乡村消费增长11.2%，但汽车、药品、文化办公用品类下滑，消费升级与收缩并存（材料[1]）。
4. **人口与财政约束**：常住人口87.53万人，自然增长率-8.16‰，人口持续负增长；税收占财政收入仅41.7%，转型期的财政与人口压力显著（材料[1]）。

**结论**：白山市产业正处于资源型经济向特色轻工、医药健康、消费型产业转型的关键期，成长期亮点集中在酒饮、医药与小型科技企业，但投资萎缩、人口负增长与税收基础薄弱构成主要约束。建议后续补充2024年分项数据、园区载体数据及龙头企业名录，以支撑更精确的产业链招商与转型路径设计。
