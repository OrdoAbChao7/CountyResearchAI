# 于都县产业发展变化、升降与转折机制研究报告（rise-fall 模式）

**说明**：本报告仅依据所给6条资料撰写。资料时间跨度约为2024年统计公报至2026年6月新闻，其中[1]为2025年1—7月数据、[2]为2026年6月报道、[3]为2024年统计公报、[4]为2026年一季度赣州市数据、[6]为2026年3月县情介绍。凡资料未覆盖的年份与指标，一律列为缺口，不作推算。


## 一、核心事实梳理（逐条标注来源）

### （一）总量与工业运行

- **事实1**：2024年，于都县实现工业增加值947850万元（约94.79亿元），较上年增长9.7%，占全县GDP比重26.9%，较上年提升0.9个百分点；规模以上工业增加值增长13.8%；规上工业总产值2090798万元，增长11.7%；规上工业营业收入207.03亿元。（来源[3]）
- **事实2**：2025年1—7月，于都县规上工业增加值增速6.5%；营业收入115.8亿元，增速4.2%；利润总额6.6亿元，同比增长38.8%；工业增值税3亿元，增长7.4%；工业售电量2.9亿千瓦时，增长7%。（来源[1]）
- **事实3**：2026年一季度，赣州市规上工业增加值同比增长9.5%，规上工业企业利润总额76.7亿元、增长93.4%。（来源[4]，为赣州市级数据，非于都县单独数据）

### （二）产业结构与分行业表现

- **事实4**：2025年1—7月，于都县纺织服装产业营收41.4亿元，同比增长5%；电子信息产业营收36.3亿元，增长15.9%；装备制造产业营收1.8亿元，增长18%。（来源[1]）
- **事实5**：2025年1—7月，天键股份（电子信息企业）营收20.2亿元，同比增长7.5%。（来源[1]）
- **事实6**：纺织服装产业2025年1—5月出口额同比增长9.54%；2025中国赣州（于都）纺织服装国际直采会订单签约金额4180万美元。（来源[1]）
- **事实7**：于都县纺织服装产业"曾长期依赖外来设计、主打代工生产"，现已集聚3800余家企业，年营收突破千亿元。（来源[2]）
- **事实8**：装备制造以竞铭机械、创芯人、鹰星精密为龙头，吸引金凯、菲格斯等配套企业；鹰星精密为国家级专精特新"小巨人"企业，其精密智造产业园项目已完成主体建设，建成后目标为"全国最大的电子信息相关配件细分领域制造基地"。（来源[1]）

### （三）要素与招商

- **事实9**：于都总人口111.95万，19—60周岁劳动力近70万，其中从事纺织服装行业的劳动力超30万；依托县职业中专、新长征技工学校等平台每年培养8000名以上产业技术型人才。（来源[6]）
- **事实10**：2025年1—7月共引进项目31个，投资总额42.304亿元；项目数同比增加13个、增长72.22%，投资总额同比增加11.674亿元、增长38.11%。（来源[1]）
- **事实11**：于都出台《关于建立"链上于都"机制促进"邻居就是上下游、园区就是产业链"的实施方案》；举办"链上坪山·于都"产业对接活动，达成初步合作意向23项；跟进对接约200名赣商总会企业家。（来源[1]）
- **事实12**：于都紧扣赣州市"7510"行动计划和县"5313"行动计划。（来源[1]）

### （四）企业与转型样本

- **事实13**：江西卫棉纺织集团智能工厂62台细纱机装传感器，通过智能制造能力成熟度三级认证，获评国家级绿色工厂。（来源[2]）
- **事实14**：赢家时装（赣州）在数字化转型中应用3D智能量体室等。（来源[2]）
- **事实15**：江西翡俪文德时装智能工厂实现智能验布、自动裁床、吊挂系统流转，"一件成衣从纱线到成品'不沾地'"。（来源[2]）


## 二、变化与升降态势分析

### （一）上升面（rise）

1. **工业总量与效益上行**：2024年规上工业增加值增长13.8%（[3]），2025年1—7月利润总额增长38.8%、工业增值税增长7.4%、售电量增长7%（[1]），显示2025年效益指标增速快于营收增速（营收仅增4.2%），呈"增收更增利"特征。**（事实）**
2. **新兴产业增速快于传统产业**：2025年1—7月装备制造营收增18%、电子信息增15.9%，均高于纺织服装的5%（[1]）。**（事实）** 由此可**推断**：产业结构正由纺织服装单极主导向"纺织服装+电子信息+装备制造"多极支撑演进，新兴产业尚小（装备制造仅1.8亿元）但增速领先。
3. **招商项目数与投资额双升**：项目数同比增72.22%、投资额增38.11%（[1]）。**（事实）**
4. **纺织服装长期规模跃升**：从"长期代工"到3800余家企业、年营收突破千亿元（[2]）。**（事实，但"千亿"为报道口径，与[1]中2025年1—7月纺织服装营收41.4亿元存在口径差异，见缺口部分）**

### （二）下行或放缓面（fall / 减速）

1. **增速回落迹象**：2024年规上工业增加值增长13.8%（[3]），2025年1—7月降至6.5%（[1]）。**（事实对比）** **推断**：增速出现明显放缓，但两年份口径（全年 vs 1—7月）不完全可比，需谨慎。
2. **传统支柱产业增速偏低**：纺织服装2025年1—7月营收仅增5%（[1]），低于电子信息、装备制造。**（事实）** **推断**：传统支柱对增长的边际贡献相对减弱。
3. **装备制造体量极小**：1.8亿元营收（[1]），虽增速18%，但绝对规模尚不足以对冲传统产业放缓。**（事实+推断）**

### （三）转折机制（rise-fall 视角下的关键节点）

- **机制1：政策与规划驱动**。"7510"行动计划、"5313"行动计划、"链上于都"机制、对标深圳规则规制改革（[1]），构成产业组织方式的转折——从企业自发集聚转向政府链式组织。**（事实+推断）**
- **机制2：数字化转型驱动**。卫棉、赢家、翡俪文德等智能工厂样本（[2]），表明生产端从劳动密集代工向数字化制造转折。**（事实）**
- **机制3：开放与出海驱动**。国际直采会签约4180万美元、出口增9.54%（[1]），纺织服装从"外来设计+代工"转向自主出海。**（事实+推断）**
- **机制4：新兴细分赛道切入**。以电镀机床、高端装备关键零部件为细分主攻方向，依托鹰星精密等打造细分制造基地（[1]），是"换道超车"式转折尝试。**（事实+推断）**


## 三、资料缺口（不可编造，明确列出）

1. **时间序列缺口**：仅有2024年全年（[3]）与2025年1—7月（[1]）两段工业数据，缺2020—2023年及2025年全年、2026年于都县单独数据；无法绘制完整升降曲线。
2. **口径缺口**：[2]称纺织服装"年营收突破千亿元"，而[1]载2025年1—7月纺织服装营收41.4亿元，二者统计口径（全行业/规上、全口径/县内）不明，无法直接衔接。
3. **结构缺口**：缺纺织服装、电子信息、装备制造三大产业各自的历史基数、企业数、就业数的时间序列；缺各产业利润、税收分项。
4. **转折归因缺口**：缺要素成本、土地、能耗、外部市场（如出口目的地）等数据，无法量化各驱动机制的贡献度。
5. **2026年数据缺口**：[4]仅为赣州市级一季度数据，不能替代于都县数据；[2]为2026年6月报道，含企业案例但缺县级汇总指标。
6. **"fall"证据缺口**：资料中未见于都县任何产业出现绝对下降（负增长）的记载，本报告的"下行"仅指增速放缓，属推断，非事实性下降。
