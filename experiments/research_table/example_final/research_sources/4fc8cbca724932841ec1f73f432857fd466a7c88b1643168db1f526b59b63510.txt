来源：中国绿色时报 【字体：大 中 小】 打印本页 分享到： ![](/r/cms/www/default/Inner_img/Zrzyb_wenz_kyy20180625_01.jpg) 川原五十里，修竹半其间。 有着“中国竹乡”美誉的安吉，境内拥有竹林面积约100万亩。竹产业是浙江省安吉县的传统优势产业。自20世纪50年代以来，安吉竹产业实现了从卖原竹向进原竹、从用竹竿向用全竹、从物理利用向生化利用、从单纯加工向链式经营的4次转变，基本实现全竹利用和高效利用，跨入了现代竹工业化利用新阶段，成为全国竹加工制造业的集群地。2023年全县竹产业总产值达到180.28亿元，同比增长8.65%，产品出口至美国、日本、荷兰、法国等30多个国家。 安吉竹林 安吉县林业局供图 近年来，由于受市场发展预期不足、产业断链风险严峻、经营理念创新匮乏、毛竹综合利用率不高等因素影响，安吉面临竹产业发展瓶颈期。安吉是如何破局，推动竹产业高质量发展的？ **优化调整产业结构** 竹刀叉、竹吸管、竹制包装盒……在浙江省湖州市安吉县梅溪镇峰晖竹木制品有限公司的生产车间，20多台数控机器开足马力，员工赶工生产。目前，安吉县竹加工企业数量近1000家，仅这一家企业就能够生产近2000种竹产品。 安吉不仅是“中国竹乡”，也是“以竹代塑”产业高质量发展的前沿阵地。 2022年以来，安吉积极推广“以竹代塑”，推动传统产业迈进新赛道。由国企出资建设，谋划参与实施“以竹代塑、以竹代气、以竹代钢”等前沿领域项目。同时，重点招引高值化、高利用率的项目或行业头部企业，从源头上提高竹材消耗量和综合利用率，短期内解决了毛竹下山难及竹林抛荒等老百姓急难愁盼问题。 提档现有产业。安吉重点拓宽现有产品应用场景，鼓励产品向“微笑曲线”的两端延伸，如笋制品向预制菜转型、竹筷向竹餐包转型、竹地板向户外重竹地板转型。加强跨界合作赋能产业，鼓励头部企业强化工业设计理念，探索传统竹材在化工能源、生物医药、能源开发、装配式建筑等领域的应用，抢占行业话语权。“随着‘以竹代塑’产品越来越受市场欢迎，我们重点打造了数字化生产线，加快技术革新和产品种类更新。”峰晖竹木制品有限公司负责人说。 补齐初加工产业链。安吉集中要素资源，由国资公司出资控股、龙头企业参与运营的形式，建设竹产业初级加工产业园，集中供热、蒸煮、碳化等，重点布局杭垓镇竹材初级加工、孝源街道竹笋初级加工，鼓励优质的小、散初加工企业腾笼换鸟、集中入园，贯通竹产业三级加工体系。 优化评价体系。优化竹产业“亩均考核”细则，探索分行业“亩均考核”体系，将竹产业富民效应、原料消耗、碳排放指标等多要素纳入考核指标，并适当给予提档升级政策。鼓励竹产业低碳绿色发展，激发企业活力，对安吉西南片区竹产业融合发展相对较好的乡镇应给予政策倾斜扶持。 **强化科技兴企思维** 去年10月，国家竹产业研究院落户安吉，竹基新材料中心、竹产品工业设计中心等相继建成，如今各项试验正在这里紧锣密鼓地进行。 安吉竹产品 安吉县林业局供图 “所有项目立项都必须有产业化基础，来源并服务于企业。通过产学研融合，旨在解决目前行业内采收成本高、规模效益差、碳排不够低等难题。”国家竹产业研究院院长张亚慧介绍。 安吉依托国家竹产业研究院、浙江省级竹产业创新服务综合体、科研院校等平台，构建“政府引导+企业出题+院校解题+平台孵化”的工作机制，每年安排科研资金及政策支持，重点攻克竹连续化生产设备改造、竹废弃物循环利用等关键技术。 “我们与研究院合作研发的一次性竹筷刀叉勺旋转式精切数控机已经正式投产，能有效减少竹材损耗，降低成本。”浙江山哥新材料科技有限公司聂忠平介绍，通过研究院牵线搭桥，公司还分别与中国林科院、浙江省林科院的竹产业专家建立了合作关系，一批新项目研发正在孵化中。 如何加大成果孵化力度？国有基金牵头，安吉建立了竹产业重大技术中试基地，对现有的科研成果可孵化的进行中试、跟投，推动科技创新成果真正与产业链匹配。 除了搭建平台，安吉举办竹产业高峰论坛、竹产业创新设计大赛、竹产业振兴大讲堂等活动，持续提升企业及合作社经营思维，宣传产业发展前沿技术、管理思维等，激发企业新动能。加大竹产业技改政策扶持力度，重点支持企业生产工艺机械化、自动化改造，降低生产成本，强化产品市场竞争力。 **扩大产品品牌影响力** 入住安吉的酒店或民宿，游客往往会被房间内的“竹六小件”洗漱用品的颜值惊艳到，竹柄的牙刷、剃须刀，竹制的拖鞋、梳子，看起来像是工艺品。目前，“竹六小件”已覆盖安吉近300家酒店民宿，覆盖率100%，累计减少一次性塑料消耗用品350余万套，为旅游住宿行业节约成本3500余万元。 一直以来，安吉挖掘竹茶包装、食品包装、竹餐包等“以竹代塑”消耗品，积极打造竹系列产品区域品牌，摆脱竹产品贴牌困境。如何开拓竹产品市场，扩大安吉竹产品品牌影响力？ 创新合作机制。依托竹林碳汇项目，安吉加快推动毛竹林资源集中经营、统一销售。发布毛竹销售指导价，推动精深加工企业与“两山公司”、合作社等签订毛竹（笋）供销协议，加快安吉县119家合作社又好又快发展，为全国订单林业改革贡献安吉案例、安吉经验。 完善加工体系。推动林业“标准地”建设，完善涉竹园区合作机制，搭建“园区+标准地+竹材分解点”竹产业加工生产体系，推动竹材（笋）精深加工企业参与竹材分解点经营，推动毛竹从下山分解到初级加工、再到精深加工全过程追溯，确保安吉竹产品品质。 加快碳评估和运用。开展安吉县竹产品碳足迹碳标签的标准化评估方法研究，以此为基础建立竹产业数智平台，加快推进竹产品碳足迹、碳标签应用，使碳排放来源透明化，引导社会低碳消费，增加竹产品需求，激励企业开展低碳生产技术研发和创新，提升竹产品的国际竞争力和企业社会形象。（左璐莹 徐薇 刘静 吴兆维） 【纠错】 关闭 个人信息*请提出您的建议意见，我们会尽快处理解决，感谢您的支持。* | | | | |
