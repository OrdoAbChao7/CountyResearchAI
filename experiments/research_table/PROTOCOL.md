# 冻结离线验证协议 v1

这是工程行为评价，不是产品效率验收；首次编写于执行新评测之前。历史 Phase 7 不变。

数据划分：real_inputs 为业务演示，仅原始存档，不读 ground_truth；synthetic_inputs 是手工构造的集成任务。两轮输入 JSON 先冻结并记录 SHA256，再执行运行器。字段候选属于输入人工录入，非标准答案；自动抽取能力另用原文规则与测试评价，不把输入候选数量当召回率。gold.json 仅在执行完成后由评分器读取，不传给导入器。无训练/调参集、无模型、无网络、无运行后挑选。

第一轮：2022/2023 年县域全口径产值、另一地区未受影响序列；按协议回放演示确认；登记增长率及文字结论。第二轮：2024 年新增、2022 年历史修订、同年园区口径、原文转载。保留冲突，不自动采用修订。

评分：受影响输出位置集合与预标位置集合比较，precision=TP/(TP+FP)，recall=TP/(TP+FN)，分母为0时 null。不同口径样例的错误计算数/尝试数；已确认事实溯源率按精确正文摘录与来源版本存在计算；缺失率按预设业务指标×地区×年份网格计算，不以已抽取事实为分母。事实值正确性仅判断预设输入的持久化保真，不代表自动抽取质量。重复导入前后事实/核查/待办集合必须不变；转载只添加来源与依据，不增加事实。另运行单元风险测试，报告案例数量与样本局限。

阈值：口径错误=0；影响 precision/recall≥0.9；确认溯源=1。合成小样本通过仅证明这些冻结工程情形，不证明真实数据上的普遍精度。人工耗时、基线正确性、40%收益均未验证。
