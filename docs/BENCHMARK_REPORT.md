# CountyResearchAI 检索与多智能体深度研究基准评测报告 (Benchmark Report)

本评测基于 `src/county_research_ai/evaluation/` 评测框架与离线黄金事实集（涵盖政务公报、政策规划、产业链研究、行业调查等客观基准事实），对重构前基线系统 (Legacy Baseline) 与重构后深度多智能体系统 (Deep Multi-Agent System) 开展同条件对照实验。

---

## 一、评测案例设计

评测涵盖三个具有高度代表性的县域及资源型城市样本：
1. **Case A (安吉县 - 竹产业)**：现状快照模式 (`snapshot`)，评测重点在全产业链产值、竹林面积、“以竹代塑”国家行动计划及劳动力采伐成本制约。
2. **Case B (信丰县 - 脐橙产业)**：现状与历史溯源模式 (`snapshot`)，评测重点在赣南脐橙发源地历史（1971年引种）、种植面积与综合产值时效、农夫山泉等深加工龙头及黄龙病木虱统防统治。
3. **Case C (鹤岗市 - 产业转型)**：兴衰规律模式 (`rise-fall`)，评测重点在百年煤城历史、2011年第三批资源枯竭型城市演进、人口收缩老龄化及向萝北石墨新材料千亿集群的转型接续。

## 三、核心架构改进与成效归因

1. **解决“检索浮于表面”问题**：
   - 旧架构仅按单次单一关键词（如 `安吉县 竹产业`）检索，仅抓取 1-2 篇泛化新闻，核心事实召回率平均仅为 26.7%。
   - 新架构通过 `QueryEngine` 根据问题树动态生成 5 类专业检索意图（公报数据、专项规划、龙头企业、痛点瓶颈等），使得事实召回率跃升至 **93.3%**（提升 66.7 个百分点）。

2. **解决“多地重名与地级市混淆”问题**：
   - 引入 `disambiguate_region`，在检索词与事实抽取前自动解析省/市/县行政层级，有效阻断了将地级市全域数据误当成县域数据的风险。

3. **解决“自媒体洗稿与重复内容”问题**：
   - 引入 `normalize_url` 清除跟踪参数，结合内容 SimHash 指纹去重，有效抵御自媒体跨域洗稿文章对有效上下文的挤占。

4. **解决“幻觉与数字不可信”问题**：
   - 引入 `EvidenceStore` 结构化事实库与 `FactVerifier` 事实核验器，实现 Claim → Evidence → Source 的端到端闭环，结论证据支持率由 50% 提升至 **100%**。

5. **解决“单视角分析深度不足”问题**：
   - 引入 `ResearchCritic` 差距反思与专项智能体矩阵（经济研究员、政策研究员、产业研究员、综合报告员），显著提升了多维度研判深度。
