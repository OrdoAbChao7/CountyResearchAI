# 人工对比实验：待执行

当前没有研究人员参与的实验，40% 人工时间下降、真实事实正确性不低于基线均未验证。演示脚本的确认人是 example-script，不属于人工实验或专家签核。合成离线回放的 synthetic-review-replay 同理。

## 预先固定的任务

研究员使用相同冻结资料做两轮工作。第一轮：整理指标定义、数据期间、地区、数值、单位、行政范围、统计口径、摘录及位置，确认后导出。第二轮：加入新资料，列出新增、历史修订、口径差异、重复信息与受影响计算/文字；不得自行联网补充。明确保留缺失，允许拒绝计算。

条件 A：通用 AI＋表格；条件 B：本项目 CLI。每个条件拿到相同 RawDoc、候选字段录入任务、10 项指标字典和相同任务说明；不要给 B 更多人工标注。若 A 使用模型而 B 用人工候选，分别记录模型与候选准备成本，不把成本隐藏在实验前。现有 real_inputs 是单县小样本，正式研究前需补齐 3–5 县近三年来源与独立答案；不能用本示例直接证明普遍收益。

让独立人员在参与者看不到的目录准备答案和口径标签，冻结其 hash；参与者及抽取程序均不得读答案。答案只在两轮提交后给评分人。任务、规则和阈值执行前签名冻结，失败和退出也保留。合成资料用于练习，正式业务效果必须用真实资料。补充资料前，真实修订/冲突效果仍未验证。

## 执行与预算

招募有县域研究经验的研究员，记录经验。采用随机分组或交叉顺序 AB/BA；交叉实验使用难度匹配的不同县资料，避免同一人第二遍记住答案。事先固定人员数量、任务数量与停止规则；建议先做小样本流程试验，再根据方差确定正式样本，不能中途看到效果就停止。

每人每条件第一轮、第二轮各设相同的人工时间上限（试验默认 45 分钟），相同资料访问权限和模型预算。免费/离线方案也必须记录模型名称、版本、token 与实际等待时间。此项目不自动调用付费服务；需要付费的基线运行须另获授权。记录 CLI 操作教学时间、初次安装/底表准备/人工确认成本，不从首次成本中扣除。

按开始、暂停、恢复、提交时间记录人工活动；等待模型时间单列，自动执行时间单列。屏幕记录需事先征得参与者同意，若不记录则人工计时并双人核对。不得把本机脚本运行时间当人工时间。

## 评分与报告

主要时间指标：第二轮每个完成任务的人工活动分钟数；减少率=(A-B)/A，A=0 时不定义。分别列首次建库、后续更新、安装教学、人工标注准备、返工耗时，报告中位数、配对差异及不确定区间。超过上限按失败/删失报告，不能剔除后只算成功者。未完成任务的质量照常评分。

正确性：正确事实/已提交事实；缺失率=缺失必需网格/全部必需网格。错误口径合并或计算=错误数/预标验收机会数，要求0。变更影响 precision/recall 以预标受影响输出位置为集合，目标各≥90%。确认溯源=能定位来源版本＋精确原文的确认事实/全部确认事实，目标100%。数据正确性与基线在同一答案和规则下比较；缺失率同时报告，不能靠少报事实提高正确率。

评价人盲化条件名称，争议由第二人复核，保留裁决理由。报告参与者数、任务数、失败数及范围限制。只有真实研究员数据支持时才能写“人工处理时间减少至少40%”；目前全部产品收益标记 NOT_VALIDATED。

记录模板见 user_study_records.csv。每个参与者×条件×轮次一行，raw_events_json 存独立计时事件路径；不要填造示例观测值。
