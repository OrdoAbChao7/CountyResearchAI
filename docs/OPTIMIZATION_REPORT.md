## 二、六大核心技术突破与工程实现

### 1. 动态问题树拆解与定向查询扩展 (`QueryEngine` & `QuestionTree`)
- **重构前**：依赖固定模板和单一搜索词（如仅搜索 `"安吉县 竹产业"`），仅能获取宽泛的自媒体新闻。
- **重构后**：依据研究模式（`snapshot` / `rise-fall` / `long-history`）自适应生成多级问题树，拆解为**历史溯源、产值指标、龙头企业、扶持政策、痛点瓶颈、未来转型**六大方向；动态派生 5 类专业检索意图，涵盖统计公报、产业专项规划与深度行业调研。

### 2. 复杂地名与行政区划消歧 (`disambiguate_region`)
- **重构前**：无法识别“黑龙江省鹤岗市”、“江西省赣州市信丰县”等多级行政前缀，常把地级市全域统计数据混淆为县域本级数据。
- **重构后**：自动解析省/市/县层级，抽取干净地名（`clean_name`），识别行政层级（`county` / `county_level_city` / `prefecture_level_city`），并绑定已知区域特征，在检索与数据抽取时提供强约束。

### 3. 细粒度结构化证据库 (`EvidenceStore`)
- **重构前**：仅简单保存文档 URL，摘要直接当作事实，缺乏指标级解析；单行多指标匹配存在提前截断与上下文污染。
- **重构后**：基于句子级精细切分，提取 `(num, unit, indicator, period, scope)` 结构化元组；独立区分“县域本级”与“全市范围”、“全产业链产值”与“规上工业产值”，支持跨年份与跨口径的聚类与自动冲突识别。

### 4. 差距驱动的反思补检回路 (`ResearchCritic`)
- **重构前**：单次检索结束即直接进入生成，对关键指标缺失无感知。
- **重构后**：借鉴 BettaFish Reflection 机制，首轮检索后由 `ResearchCritic` 审查问题树覆盖度，主动探测“核心产值是否缺失”、“历史起源是否模糊”、“数据是否过时”，自动生成补充搜索词，触发第 2 轮定向补检，受最大轮数与去重约束保护。

### 5. 专业智能体协同矩阵 (`Specialized Agents`)
- **重构前**：单一 LLM 调用完成所有维度的分析，容易顾此失彼。
- **重构后**：划分 4 个专业角色：
  - **经济研究员 (`EconomicResearchAgent`)**：专注产值、增速、财税贡献与数据口径；
  - **政策研究员 (`PolicyResearchAgent`)**：梳理国家/省/县级专项规划与扶持方案；
  - **产业研究员 (`IndustryResearchAgent`)**：梳理龙头企业、上下游链条与竞争格局；
  - **综合报告员 (`ResearchSynthesizer`)**：消除冗余，汇总不同视角研判，并提供无 API Key 时的安全启发式降级。

### 6. 严苛的双向事实核验器 (`FactVerifier`)
- **重构前**：仅凭最终文本挂载超链接，模型可能“幻觉”捏造具体统计数字。
- **重构后**：建立 `(num, unit)` 结构化元组索引与专名索引，逐句核对正文数据是否具备底层权威证据支持。若文本出现无证据数据，显式降级为未核验声明，并在报告文末追加《证据链与可信度审计记录》。

## 六、总结

本次架构重构未追求形式化的 Agent 数量堆砌，而是切实围绕**“真实检索能力、研究深度挖掘、事实证据可靠”**三大底线构建闭环。重构后的系统具备了自主拆解研究课题、动态发现信息盲区、主动补充检索、识别统计口径差异与多角色协同总结的专业研究员级能力，显著提升了县域经济与区域产业研究初稿的专业度与可信度。
