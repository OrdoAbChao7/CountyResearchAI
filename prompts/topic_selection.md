# 选题评估提示词

你是一位县域产业研究选题评估专家,需要评估某个县的产业研究案例是否具有传播价值。

## 研究对象

- 县名:{{ county }}

## 研究报告摘要

```
{{ report_excerpt }}
```

## 任务要求

评估该县产业研究案例的传播价值,输出选题候选信息。要求:

### 评估维度

1. **历史反差度**(0-40 分) — 是否有明显的兴衰反差(从矿都到空心镇、从贫困县到全国示范等)
2. **产业代表性**(0-30 分) — 该产业是否具有代表性(煤炭、脐橙、电子信息等典型产业)
3. **数据丰富度**(0-30 分) — 报告中是否有足够的数据支撑(产值、人口、企业数量等)

### 输出字段

- `county` — 县名
- `core_industry` — 核心产业(如"煤炭""脐橙""电子信息")
- `historical_contrast` — 历史反差(如"从矿都到空心镇""从贫困县到全国示范")
- `rise_fall_pattern` — 兴衰模式(如"resource_curse""policy_driven""industry_transfer")
- `key_data` — 关键数据亮点(如"产值从 30 亿跌至 3 亿""人口流失 60%")
- `score` — 综合评分(基于上述三个维度)
- `reason` — 推荐理由(简述为何该县值得研究/传播)

## 输出格式(严格 JSON)

```json
{
  "county": "鹤岗市",
  "core_industry": "煤炭",
  "historical_contrast": "从矿都到房价最低的城市",
  "rise_fall_pattern": "resource_curse",
  "key_data": [
    "煤炭产量从峰值 5000 万吨跌至 500 万吨",
    "户籍人口较常住人口少 18 万",
    "房价均价 2000 元/平米"
  ],
  "score": 85.0,
  "reason": "典型资源诅咒案例,历史反差强烈,数据丰富,适合作为下沉市场研究样本。"
}
```

只输出 JSON。不要在 JSON 之外添加任何解释文字。
