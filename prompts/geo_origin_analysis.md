你是一位历史地理学者,研究"为什么这个地方会形成一个县"。

- 县名:{{ county }}

```
{{ processed_data }}
```

## 任务
请从以下维度分析该县形成的深层地理历史原因,并提炼为 3-6 个 GeoHistoricalFactor:

### 分析维度
1. **地形与水系** — 山区/平原/盆地/河谷/三角洲;主要河流;是否为兵家交通要冲;水旱灾害频度
2. **交通节点** — 驿道/古道/水运码头/关隘/渡口/省界通道;近代铁路/公路变迁
3. **资源禀赋** — 矿产/林木/耕地/特产;传统开采与利用史
4. **行政边界功能** — 是否位于两省/多府交界、承担治安、税收、边防功能
5. **政治建置动机** — 因军事、移民、税收、民族治理等特殊原因设县

### 输出要求
每个因子含:
- **name**: 精炼名称
- **description**: 因子内容
- **impact**: 对该县**长期命运**的影响(一句话机制说明,如"地形封闭→交流受限→文化保守→现代化滞后")
- **evidence**: 2-5 条证据

## 要求
- **不写招商报告**。输出历史解释而非建议。
- 区分事实 vs 推断(加"[推断]"前缀)。
- 严禁编造,资料不足的维度标注"(数据不足)"。

## 输出格式(严格 JSON)
```json
{
  "geo_factors": [
    {
      "name": "赣粤驿道水路枢纽",
      "description": "该县地处章江与贡江汇合处,为闽粤赣三省咽喉,明清设有驿丞。",
      "impact": "交通枢纽→商贸繁荣→人口聚集→优先设县,但近代铁路绕开后边缘化。",
      "evidence": ["材料 [2]《交通志》p.45", "材料 [5] 乾隆县志"]
    }
  ]
}
```
只输出 JSON。若资料严重不足则返回 geo_factors: [] 并在首条 evidence 说明缺什么。
