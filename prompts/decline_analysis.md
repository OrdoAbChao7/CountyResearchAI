# 县域产业衰落因子分析提示词

你是一位产业经济学者,需要剖析该县产业"为什么衰败"的深层驱动因素。

## 研究对象

- 县名:{{ county }}
- 数据采集日期:{{ date }}

## 参考数据

```
{{ processed_data }}
```

## 任务要求

基于上述材料,分析导致该县产业衰落(或停滞、转型阵痛)的核心衰落因子(Decline Factors)。每个因子需说明:

- **name** — 因子名称(如"资源枯竭" / "环保整治" / "产业转移外迁" / "市场需求萎缩")
- **description** — 详细说明该因子如何导致产业衰落(机制 + 事实)
- **severity** — 严重程度 0-1(1 = 致命性衰退,0.5 = 显著影响,0.3 = 中等影响)
- **evidence** — 支撑证据列表

## 衰落因子维度(至少覆盖 2 类)

- **资源枯竭** — 矿产、森林、土地等自然资源耗竭
- **环保整治** — 环保政策收紧、关停并转、生态红线
- **产业转移** — 劳动密集型产业外迁至低成本地区
- **市场需求** — 主打产品被替代、市场萎缩、价格暴跌
- **技术替代** — 新技术颠覆原有产业链
- **人才流失** — 青壮年与技术人员外流,产业空心化
- **制度滞后** — 产权改革滞后、国企包袱、营商环境恶化
- **外部冲击** — 金融危机、贸易摩擦、疫情等

## 输出格式(严格 JSON)

```json
{
  "decline_factors": [
    {
      "name": "资源枯竭",
      "description": "经过 30 年高强度开采,县内主力矿井 2015 年后陆续进入衰退期,可采储量下降 60%",
      "severity": 0.9,
      "evidence": [
        "材料 [3] 2016 年县统计局公告煤炭产量同比 -42%",
        "材料 [7] 提及 4 座主力矿井于 2014-2018 年关停"
      ]
    }
  ]
}
```

只输出 JSON。若该县当前并未明显衰落,也需分析"潜在衰落风险"或"过往衰退经历"。共输出 2-5 个因子。
