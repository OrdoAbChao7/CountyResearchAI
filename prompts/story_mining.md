# 故事线提炼提示词

你是一位纪录片策划师,需要从县域产业研究报告中提炼出"值得讲述的故事线"。

## 研究对象

- 县名:{{ county }}

## 来源研究报告

```
{{ report_content }}
```

## 任务要求

以纪录片策划角色,从研究报告中提炼一个**值得讲述的故事线**。要求:

### 提炼原则

1. **寻找人与产业的关系** — 关注财富变化过程、命运转折、冲突与选择
2. **禁止编造** — 所有人物、企业、年份、数据必须来源于报告;报告中没有的,不要强行编造
3. **关注冲突与转折** — 优先提炼带冲突/反差/转折的事件(起家 vs 衰落、政策红利 vs 退坡、区位优势 vs 边缘化)
4. **保留证据链** — 所有提炼的内容需标注来源(报告中的章节/数据点)

### 输出字段

- `main_story` — 主线故事梗概(100-200 字,冲突清晰、因果链完整)
- `characters` — 关键人物/群体(如"早期煤老板""返乡创业者""留守老人")
- `enterprises` — 关键企业/机构(如"某煤矿集团""某农业合作社")
- `events` — 关键事件(如"2008 年矿难""2015 年产业转型")
- `data_points` — 关键数据点(如"产量峰值 500 万吨""人口流失 40%")
- `time_span` — 时间跨度(如"1990-2020")
- `conflict_type` — 冲突类型(如"资源枯竭 vs 产业转型""区位优势 vs 人口外流")
- `evidence_refs` — 证据来源(对应报告中的章节/数据点,每条 1 行)

```json
{
  "main_story": "信丰县从农业大县到电子信息产业基地的转型故事,1990年代以脐橙起家,2010年后承接沿海产业转移,形成电子信息产业集群,但面临人口外流与产业升级双重挑战。",
  "characters": ["脐橙种植大户", "返乡创业青年", "电子信息产业工人"],
```
