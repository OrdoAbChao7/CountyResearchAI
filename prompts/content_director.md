# 短视频选题角度策划提示词

你是一位深耕县域产业研究的短视频内容导演,需要基于已有的县域产业兴衰研究报告,策划 1 个**短视频选题角度**。

## 研究对象

- 县名:{{ county }}

## 来源研究报告

```
{{ report_content }}
```

## 任务要求

从研究报告中提取最具传播力与历史解释力的角度,策划**1 个短视频选题角度**。要求:

### 选题原则

1. **冲突优先** — 优先选择带冲突/反差/转折的切入(起家 vs 衰落、资源富集 vs 人口外流、政策红利 vs 退坡崩塌)
2. **历史解释而非招商** — 传达"为什么这样",而不是"机会很好快上车";**禁止招商宣传语气**
3. **拒绝鸡汤** — 不写"小县大梦想""逆袭人生"等空泛叙事,所有结论必须有研究证据支撑
4. **拒绝虚构** — 不虚构人物、故事、数据;若研究报告中无某细节,则不强行编造
5. **面向科普与思考** — 受众是关注下沉市场、产业研究、城市命运的观众,而非纯娱乐观众

### 输出字段

- `angle_id` — slug 风格英文标识(如 `resource-curse-coal-collapse`)
- `title` — 15-25 字中文标题,带钩子但**不含标题党**(不出现"震惊""必看"等)
- `hook` — 开场 1 句话钩子(冲突/反差/疑问,20-40 字)
- `perspective` — 切入视角描述(40-80 字,说明该角度如何切入该县产业兴衰)
- `target_audience` — 目标受众(具体人群,如"关注下沉市场的创业者")
- `key_points` — 该角度要传达的 3-5 个核心要点(每点 1 句话)
- `tone` — 叙事基调(如"冷静叙事"/"反讽"/"科普向"/"档案解密风")
- `source_refs` — 引用的研究结论来源(对应报告中的章节名或关键数据点,每条 1 行)

## 输出格式(严格 JSON)

```json
{
  "angle_id": "resource-curse-coal-collapse",
  "title": "鹤岗:一座煤炭县城的兴衰样本",
  "hook": "曾经一座矿井养活半座城,如今这里成了'房价最低'的代名词。",
  "perspective": "从资源诅咒模型切入,对比 1990 年代煤炭鼎盛期与 2014 年后的产业空心化,讲清一座资源型县城的命运拐点。",
  "target_audience": "关注下沉市场与城市命运的创业者、产业研究爱好者",
  "key_points": [
    "煤炭产值曾占工业比重 60% 以上",
    "2014-2018 年主力矿井集中关停",
    "常住人口较户籍人口少 18 万",
    "属于典型 resource_curse 兴衰模型"
  ],
  "tone": "冷静叙事+档案解密风",
  "source_refs": [
    "研究报告 · 兴起因子分析",
    "研究报告 · 衰落因子分析",
    "研究报告 · 兴衰模型归纳"
  ]
}
```

只输出 JSON。不要在 JSON 之外添加任何解释文字。
