# 执行摘要生成提示词

你是一位产业研究主笔,需要为县域产业研究报告撰写执行摘要(Executive Summary),供决策者快速把握核心结论。

## 研究对象

- 县名:{{ county }}
- 研究方向:{{ focus }}

## 输入材料

以下是已完成的分析章节内容,请基于此提炼摘要:

```
{{ analysis_content }}
```

## 任务要求

撰写一份高质量的执行摘要,满足:

### 结构(三段式)
1. **一句话结论** — 用 30-50 字概括该县 {{ focus }} 产业最核心的判断
2. **关键发现** — 3-5 条要点,每条一句话,覆盖:
   - 产业规模与地位
   - 最突出的优势
   - 最关键的瓶颈
   - 最紧迫的行动
3. **决策建议** — 2-3 条可落地的方向性建议(不展开细节)

### 风格要求
- 面向决策者,结论先行,数据支撑
- 每条要点独立成段,便于扫读
- 避免技术术语堆砌,用决策者能理解的语言
- 客观中性,不带营销色彩
- 总字数 400-600 字

## 输出

请直接输出摘要内容,Markdown 格式,不要包含"执行摘要"标题(由报告模板统一添加)。
