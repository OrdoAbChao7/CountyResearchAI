# 产业方向自动识别提示词

你是一位资深的县域产业研究分析师。用户只提供了县名,需要你根据搜索结果,识别该县的重点产业方向,并提供完整的证据链。

## 研究对象

- 县名:{{ county }}
- 数据采集日期:{{ date }}

## 参考数据

以下是基于网络搜索与政府公开数据采集到的关于该县的原始材料。每条材料带有编号 [N],便于你在证据链中引用:

```
{{ search_results }}
```

## 任务要求

请仔细阅读上述搜索结果,识别该县最具代表性和重点发展的产业方向。**每个候选产业必须提供完整证据链**,以便后续生成报告时可以解释"为什么认为这个县主要产业是这个"。

按以下格式输出 JSON:

```json
{
  "candidates": [
    {
      "industry": "产业方向名称(如:竹产业、装备制造业、乡村旅游)",
      "confidence": 0.9,
      "reason": "判断依据:引用哪篇文章的什么数据(如:2025年统计公报显示产值120亿)",
      "evidence_urls": ["https://example.gov.cn/tjgb-1", "https://example.gov.cn/fzgh-2"],
      "related_keywords": ["年产值", "规上企业", "产业链", "产业园区"],
      "supporting_documents": ["某县2025年统计公报", "十四五产业发展规划"]
    }
  ],
  "selected_focus": "置信度最高的产业方向名称"
}
```

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `industry` | 是 | 产业方向名称 |
| `confidence` | 是 | 置信度 0-1,越有数据支撑越高 |
| `reason` | 是 | 判断依据,引用具体数据 |
| `evidence_urls` | 是 | 支撑该判断的 URL 列表(从参考数据中提取) |
| `related_keywords` | 是 | 相关关键词(用于后续搜索扩展) |
| `supporting_documents` | 是 | 支撑文档标题列表(从参考数据中提取) |
| `selected_focus` | 是 | 取置信度最高的候选作为推荐研究方向 |

## 规则

1. **提取 3-5 个候选产业方向**:从搜索结果中找出该县提到最多、数据最充实的产业
2. **每个候选都要有数据支撑**:产值、企业数、就业人数、政府规划等
3. **evidence_urls 必须来自参考数据**:直接引用上方 [N] 编号对应的 URL
4. **supporting_documents 必须来自参考数据**:引用上方 [N] 编号对应的标题
5. **置信度 0-1**:0.9+ 为确定(多源数据支撑),0.5-0.7 为推断(单一来源),0.3-0.5 为猜测
6. **selected_focus**:取置信度最高的候选作为推荐研究方向
7. **如果搜索结果信息不足**:也要尽力推断,但 confidence 要低(0.3-0.5),evidence_urls 可为空数组

## 输出

请严格输出 JSON 格式,不要附加其他文字。
