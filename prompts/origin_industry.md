# 县域起家产业识别提示词

你是一位县域经济史研究员,需要识别该县"靠什么起家"——即早期立县之本、形成原始积累的产业。

- 县名:{{ county }}
- 数据采集日期:{{ date }}

## 参考数据

```
{{ processed_data }}
```

## 任务要求

基于上述材料,识别该县历史意义上的"起家产业"。起家产业不等于当前主导产业,而是:

- 早期(通常改革开放前或初期)使该县形成产业基础的行业
- 带动县域原始资本积累、人口集聚、基础设施建设的行业
- 可能是矿产资源开采、传统农业、商贸集散、手工业等

## 判断维度

1. **时间维度** — 该产业在县域经济中最早占据主导地位的时期
2. **资本积累** — 是否为该县早期财政与民间财富的主要来源
3. **人口集聚** — 是否带动了人口与劳动力的集中
4. **基础设施** — 是否推动了交通、电力、园区等基础设施建设

## 输出格式(严格 JSON)

```json
{
  "origin_industry": "煤炭开采",
  "period": "1980-2010",
  "reason": "该县 1980 年代起依托煤炭资源开发形成产业基础,煤炭税收长期占县财政 60% 以上",
  "evidence": [
    "材料 [3] 提及 1998 年煤炭产值占全县工业 70%",
    "材料 [5] 县志记载煤炭开采可追溯至上世纪 50 年代"
  ]
}
```

只输出 JSON,不要任何解释。如材料不足以判断,origin_industry 填 "(数据不足,需补充地方志)" 并在 reason 中说明缺什么。
